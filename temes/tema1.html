Tema 1 · Sessió de 3 hores

Variables: guardar informació

Fins ara el programa sempre deia el mateix. A partir d'ara guardarà informació: punts, vides, notes, preus, noms… i podrà canviar-la mentre funciona.

⏱ 3 hores 📦 Fase 1 · Pensament de programador 🧩 Necessites: Tema 0 ⌨️ 60-75 min programant

Una situació per començar

🎮

Estàs fent un videojoc. El jugador comença amb 0 punts i 3 vides. Mata un enemic i guanya 250 punts. Rep un colp i perd una vida. Arriba a 1500 punts i puja de nivell.

On guarda el programa tot això? El text del Tema 0 estava escrit dins del codi i no canviava mai. Un joc necessita guardar coses que van canviant: la puntuació, les vides, el nivell…

La solució és una variable: una caixa amb un nom on guardem informació, que podem llegir i canviar quan vulguem. És el concepte més important del tema i la base de tot el que vindrà: si no domines les variables, tot el demés costa el doble.

Abans de començar has de poder fer això:
  • Crear i executar un programa en Java (Tema 0).
  • Mostrar text per pantalla amb System.out.println().
  • Saber que cada instrucció acaba en ; i que el fitxer ha de dir-se igual que la classe.

Què aprendrem en este tema?

En acabar esta sessió has de saber fer estes coses:

  • 1Crear variables dels tipus bàsics: int, double, boolean, char i String.
  • 2Guardar un valor, canviar-lo i mostrar-lo per pantalla.
  • 3Fer càlculs amb els operadors +, -, *, / i %.
  • 4Distingir nombres enters i decimals, i saber quan Java «perd» els decimals.
  • 5Demanar dades a l'usuari pel teclat amb Scanner.
  • 6Escriure missatges que barregen text i variables.

Teoria, poc a poc

Una idea → un exemple. Prova cada exemple mentre el lliges: així no s'oblida.

1. Una variable és una caixa amb nom

Imagina una capsa de cartó amb una etiqueta on posa punts. Dins de la capsa hi ha un nombre. Si volem canviar la puntuació, traiem el que hi ha i posem una altra cosa. La capsa sempre és la mateixa; el contingut canvia.

public class PrimeraVariable {
            public static void main(String[] args) {
                int punts = 0;                 // una caixa que es diu punts i guarda 0
                System.out.println(punts);     // mostrem el que hi ha dins

                punts = 10;                    // canviem el contingut de la caixa
                System.out.println(punts);

                punts = punts + 25;            // el que hi havia dins, més 25
                System.out.println(punts);
            }
        }
Eixida per pantalla 
0
        10
        35
💡

punts = punts + 25; no és cap broma ni una equació: vol dir «agafa el valor de dins de la caixa punts, suma-li 25 i torna a guardar el resultat a la mateixa caixa». És la instrucció que més faràs servir en tota la teua vida de programador.

2. Declarar i assignar

Quan creem una variable fem dos coses: declarar-la (dir com es diu i de quin tipus és) i assignar-li un valor.

int edat;        // declare: volem una caixa de nombres enters que es diu edat
        edat = 16;       // assigne: dins hi guarde el 16

        int vides = 3;   // les dos coses a la vegada (el més habitual)

La primera part (int) és el tipus de dada que hi cap a dins. La segona (edat) és el nom. El = es llig «guarda dins» i no és una comparació.

⚠️

Si declares una variable i no li dones cap valor, no la pots usar: Java no sap què hi ha dins i et dirà variable might not have been initialized. Sempre és millor donar-li un valor quan la crees.

3. El tipus no es pot canviar

Una capsa d'enters només guarda enters; una de text, només text. Java és estricte amb això i no et deixarà barrejar-ho per accident.

int edat = "setze";

error: incompatible types: String cannot be converted to int

Eixe missatge ens diu exactament el problema: estem intentant guardar un text (String) dins d'una caixa de nombres enters (int). I tindrá tot el sentit quan penseu: «i si volem guardar l'edat com a text per posar-la dins d'una frase?» No cal: per a això ja tenim la concatenació.

4. Els tipus bàsics

TipusQuè guardaExemple
intNombres enters (sense decimals)int edat = 16;
doubleNombres amb decimalsdouble nota = 7.5;
booleanVertader o falsboolean aprovat = true;
charUn sol caràcterchar lletra = 'A';
StringText (una cadena de caràcters)String nom = "Ana";
  • Nombres per comptar coses (punts, vides, edat, quantitat): int.
  • Nombres que poden tindre decimals (notes, preus, temperatures, alçades): double.
  • Coses que només poden ser sí o no (aprovat, és major d'edat, té clau): boolean.
  • Una lletra solta (una inicial, una opció de menú): char.
  • Noms, títols, frases: String.
ℹ️

Els textos (String) van entre cometes dobles i els caràcters solts (char) entre cometes simples: String resposta = "sí"; però char inicial = 'A';. Confondre-ho és l'error número u d'este tema.

5. Com es diuen les variables

El nom el tries tu, però hi ha normes i costums: les normes les imposa Java i les costums les imposem nosaltres perquè el codi s'entenga.

  • No pot tindre espais ni accents: puntsTotals, no punts totals ni punts_totals_2026.
  • No pot començar per un número: nivell1 sí, 1nivell no.
  • En Java s'escriu camelCase: primera paraula en minúscula i les següents amb majúscula: puntsDeVida, preuAmbIva.
  • El nom ha de dir què guarda: edats, no x. Dins d'una setmana no te'n recordaràs.
💡

Sorpresa: Java sí que accepta accents i la ç en els noms de variables, però per costum no els fem servir. Escrivim mitjana (sense accents) perquè el codi no done mai problemes si l'obrim en un altre ordinador o el copiem a un altre programa.

6. Els operadors aritmètics

Amb les variables podem calcular. Estos són els cinc operadors de sempre:

OperadorQuè faExemple amb a = 7 i b = 2
+Sumaa + b → 9
-Restaa - b → 5
*Multiplicacióa * b → 14
/Divisióa / b → 3 (si són enters!)
%Residu: el que sobra de la divisióa % b → 1

El residu (%) pareix estrany però és molt útil: 7 % 2 és 1 perquè 7 dividit per 2 dona 3 i sobra 1. Servix, per exemple, per saber si un nombre és parell o per repartir coses en grups.

7. Compte amb la divisió entre enters!

Ací hi ha un parany que fa caure a tots els principiants. Pensa què apareixerà abans d'executar:

Què apareixerà per pantalla?

int a = 9;
        int b = 2;
        System.out.println(a / b);
        System.out.println(a % b);
        System.out.println(a / 2.0);
Resposta
Eixida real
4
        1
        4.5

Per què: Quan els dos costats de la divisió són enters, Java fa la divisió entera i llença la part decimal: 9/2 dona 4, no 4.5. Si un dels dos és double (per exemple 2.0), el resultat sí que porta decimals. No és un error de Java: és una regla del llenguatge que hem de conéixer.

⛔

Si vols decimals, almenys un dels dos nombres ha de ser double. Escriu 9 / 2.0, o guarda els nombres en variables double des del principi. Ensopegar amb açò és tan habitual que té nom propi: la divisió entera.

8. Combinar text i variables

Per mostrar un resultat amb un missatge, s'enganxen les peces amb l'operador +. Este procés es diu concatenació.

public class Missatge {
            public static void main(String[] args) {
                String nom = "Ana";
                int punts = 350;

                System.out.println("Hola, " + nom + "!");
                System.out.println("Tens " + punts + " punts.");
                System.out.println("La meitat de punts: " + punts / 2);
            }
        }
Eixida per pantalla 
Hola, Ana!
        Tens 350 punts.
        La meitat de punts: 175

Quan un dels costats del + és un text, l'altre es convertix en text i s'enganxen. Per això "Tens " + punts dona Tens 350.

⛔

Compte amb l'orde! "Total: " + a + b no suma, enganxa: si a és 3 i b és 4, mostra Total: 34. Si vols sumar de veritat, tanca la suma entre parèntesis: "Total: " + (a + b).

9. Que l'usuari escriga dades: Scanner

Fins ara el programa sempre deia el mateix. Amb Scanner el programa pot demanar dades i treballar amb elles.

import java.util.Scanner;

        public class Endevina {
            public static void main(String[] args) {
                Scanner teclat = new Scanner(System.in);   // el nostre lector de teclat

                System.out.print("Escriu un número: ");
                int numero = teclat.nextInt();             // espera i guarda el nombre

                System.out.println("Has escrit el " + numero);
            }
        }
Què ha de passar 
Escriu un número: 42
        Has escrit el 42
  • La primera línia (import java.util.Scanner;) va sempre a dalt del fitxer, abans de la classe. Es copia tal qual.
  • Scanner teclat = new Scanner(System.in); es crea una sola vegada, al principi del main. El nom teclat el triem nosaltres.
🔧

De moment no necessitem entendre esta part. les línies import java.util.Scanner; i new Scanner(System.in) formen part del que anomenem carcassa: cal escriure-les perquè funcione, però no cal entendre-les encara.

Una vegada tenim el lector, podem llegir el que l'usuari escriu amb estos mètodes:

MètodeQuè lligEs guarda en
teclat.nextInt()Un nombre enterint
teclat.nextDouble()Un nombre amb decimalsdouble
teclat.next()Una paraula (sense espais)String
teclat.nextLine()Una línia senceraString
⚠️

Els decimals s'escriuen amb punt (7.5), no amb coma. I si l'usuari escriu una lletra quan el programa espera un número, el programa s'atura amb l'error InputMismatchException: ho veurem en l'apartat d'errors.

ℹ️

¿I si volem llegir una línia sencera amb espais desprès d'un número? Hi ha un detall famós que ho fa fallar. De moment fem servir next() per a una paraula i ho deixem per a més avant; quan ens passe, el tindrem en l'apartat d'errors d'este tema.

10. Un programa complet

Ajuntem-ho tot: dades, càlcul i missatge final. Este programa calcula el preu d'un producte amb IVA.

public class PreuAmbIva {
            public static void main(String[] args) {
                double preu = 20.0;            // preu del producte
                double iva = 0.21;             // 21 % d'IVA

                double total = preu + preu * iva;

                System.out.println("Preu sense IVA: " + preu + " euros");
                System.out.println("IVA (21%):      " + preu * iva + " euros");
                System.out.println("Total a pagar:  " + total + " euros");
            }
        }
Eixida per pantalla 
Preu sense IVA: 20.0 euros
        IVA (21%):      4.2 euros
        Total a pagar:  24.2 euros
ℹ️

Fixa't que Java escriu 20.0 i 4.2: no posa zeros que no calen i sempre mostra el punt decimal. Més avant aprendrem a arredonir a dos decimals per mostrar diners de veritat.

Exemples explicats pas a pas

Cada exemple: què volem aconseguir, el codi, què apareix per pantalla i per què funciona.

Exemple 1 · Els punts d'una partida

Què volem? Guardar la puntuació i les vides d'un jugador i vore com canvien després d'una pantalla.

public class Partida {
            public static void main(String[] args) {
                int punts = 1200;
                int vides = 3;

                punts = punts + 250;      // hem superat una pantalla
                vides = vides - 1;        // ens han tocat

                System.out.println("Punts: " + punts);
                System.out.println("Vides: " + vides);
                System.out.println("Nivell: " + punts / 500);
            }
        }
Eixida per pantalla 
Punts: 1450
        Vides: 2
        Nivell: 2

Per què funciona: punts + 250 es calcula i el resultat es guarda a la mateixa variable. En l'última línia hi ha una divisió entre enters: 1450 / 500 és 2, perquè la part decimal es perd. Per a este joc ens va bé: el nivell es puja per trams complets.

Exemple 2 · La temperatura

Què volem? Convertir graus Celsius a Fahrenheit. Per a això cal treballar amb decimals, perquè la temperatura no sempre és un nombre rodó.

public class Temperatura {
            public static void main(String[] args) {
                double celsius = 21.5;
                double fahrenheit = celsius * 9 / 5 + 32;

                System.out.println(celsius + " graus Celsius són " + fahrenheit + " graus Fahrenheit.");
            }
        }
Eixida per pantalla 
21.5 graus Celsius són 70.7 graus Fahrenheit.

Per què funciona: com que celsius és double, tota l'operació es fa amb decimals encara que hi haja un 9 i un 5 enters. Si celsius haguera sigut int, el resultat seria un desastre: 21 * 9 / 5 donaria 37 en compte de 37.8.

Exemple 3 · Els diners que queden

Què volem? Saber quant ens queda després de gastar. I sumar el que hem gastat entre parèntesis, que és un parany habitual.

public class Cartera {
            public static void main(String[] args) {
                double diners = 20.0;
                double entrepa = 4.75;
                double beguda = 1.25;

                double queda = diners - entrepa - beguda;

                System.out.println("Tens " + diners + " euros.");
                System.out.println("Has gastat " + (entrepa + beguda) + " euros.");
                System.out.println("Et queden " + queda + " euros.");
            }
        }
Eixida per pantalla 
Tens 20.0 euros.
        Has gastat 6.0 euros.
        Et queden 14.0 euros.

Per què funciona: els parèntesis obliguen a fer primer la suma del gastat, i després eixe resultat s'enganxa al text. Sense parèntesis, eixiria Has gastat 4.751.25 euros.

Exemple 4 · La nota mitjana

Què volem? Calcular la mitjana de tres notes. Mira bé l'eixida: hi ha una cosa que a tots ens sorprén el primer dia.

public class Mitjana {
            public static void main(String[] args) {
                double nota1 = 6.0;
                double nota2 = 7.0;
                double nota3 = 8.0;

                double suma = nota1 + nota2 + nota3;
                double mitjana = suma / 3;

                System.out.println("Suma: " + suma);
                System.out.println("Mitjana: " + mitjana);
            }
        }
Eixida per pantalla 
Suma: 21.0
        Mitjana: 7.0

Per què funciona: la suma dona 21 i la divisió 7, però Java escriu 21.0 i 7.0 perquè les variables són double. No és un error: és la manera que té Java de dir «este nombre pot tindre decimals».

💡

Pregunta-la a classe: «i si les notes foren int i dividim per 3?» La resposta és 7 sense decimals… i amb notes reals (6.5, 7.0, 8.5) l'arrodoniment cap avall seria un problema de veritat.

Què apareixerà per pantalla?

Pensa-ho abans d'executar. Ací es veu molt bé com afecta l'orde de les operacions.

Pensa abans d'executar

int a = 3;
        int b = 4;
        System.out.println("Total: " + a + b);
        System.out.println("Total: " + (a + b));
Resposta
Eixida real
Total: 34
        Total: 7

Per què: En la primera línia, quan Java troba el + entre un text i un número, convertix tot el que ve després en text i l'enganxa: per això ix 34. Amb els parèntesis, primer es fa la suma i després s'enganxa el resultat: 7.

Programació guiada: ho fem junts

Construïm una calculadora de la paga setmanal: demanarà les hores treballades i quant es cobra per hora, i dirà quant es guanya. Pas a pas, provant cada pas.

1

Pensem el problema abans de tocar el teclat

Sempre igual: primer les idees i després el codi. Estos tres passos els farem servir tota la vida.

  • Què ha d'entrar? Les hores treballades i el preu de cada hora. Les dos coses les sap l'usuari → Scanner.
  • Què ha de passar? Una multiplicació: hores × preu.
  • Què ha d'eixir? Un missatge amb el resultat.

Les hores poden ser 7.5 (mitja hora)? I el preu, pot ser 12.50 €? Què significa això per als tipus que hem de triar?

Si pot haver-hi mitja hora, les dos dades són double. Si haguérem decidit que només comptem hores senceres, serien int. Sempre pensem en les dades abans de programar.

2

Escrivim el que sí que sabem

Carcassa, Scanner i les dos preguntes. Ho provem amb unes dades qualsevol per comprovar que llig bé.

import java.util.Scanner;

          public class CalculadoraPaga {
              public static void main(String[] args) {
                  Scanner teclat = new Scanner(System.in);

                  System.out.print("Quantes hores has treballat? ");
                  double hores = teclat.nextDouble();

                  System.out.print("Quant cobres per hora? ");
                  double preuHora = teclat.nextDouble();

                  System.out.println("Hores: " + hores);
                  System.out.println("Preu per hora: " + preuHora);
              }
          }
Què ha de passar 
Quantes hores has treballat? 7.5
          Quant cobres per hora? 12.5
          Hores: 7.5
          Preu per hora: 12.5
3

Afegim el càlcul

Una variable nova per al resultat i una multiplicació. Fixa't que la variable la creem damunt del println, perquè si no, no existiria.

import java.util.Scanner;

          public class CalculadoraPaga {
              public static void main(String[] args) {
                  Scanner teclat = new Scanner(System.in);

                  System.out.print("Quantes hores has treballat? ");
                  double hores = teclat.nextDouble();

                  System.out.print("Quant cobres per hora? ");
                  double preuHora = teclat.nextDouble();

                  double total = hores * preuHora;

                  System.out.println("Hores: " + hores);
                  System.out.println("Preu per hora: " + preuHora);
                  System.out.println("Total: " + total + " euros");
              }
          }
Què ha de passar 
Quantes hores has treballat? 7.5
          Quant cobres per hora? 12.5
          Hores: 7.5
          Preu per hora: 12.5
          Total: 93.75 euros

Què passaria si haguérem declarat les hores com a int i l'usuari escriu 7.5?

4

Millorem el missatge final

El programa funciona, però el resultat barreja dades i càlcul. Traiem les línies de comprovació i deixem un missatge clar, com faria una aplicació de veritat.

import java.util.Scanner;

          public class CalculadoraPaga {
              public static void main(String[] args) {
                  Scanner teclat = new Scanner(System.in);

                  System.out.print("Quantes hores has treballat? ");
                  double hores = teclat.nextDouble();

                  System.out.print("Quant cobres per hora? ");
                  double preuHora = teclat.nextDouble();

                  double total = hores * preuHora;

                  System.out.println("Has treballat " + hores + " hores a " + preuHora + " euros/hora.");
                  System.out.println("Esta setmana cobraràs " + total + " euros.");
              }
          }
Què ha de passar 
Quantes hores has treballat? 7.5
          Quant cobres per hora? 12.5
          Has treballat 7.5 hores a 12.5 euros/hora.
          Esta setmana cobraràs 93.75 euros.
5

Trenquem-lo: proves i preguntes

Un programa no està acabat fins que l'hem provat amb casos estranys. Provem estos i apuntem què passa:

  1. 0 hores → total 0.0. Està bé.
  2. 160 hores → funciona. Compensa comprovar-ho.
  3. 7,5 (amb coma) → el programa s'atura amb InputMismatchException. Java espera un punt!
  4. Una lletra qualsevol → el mateix error, i el programa es tanca.

Eixe error de la coma és real i li passa a molta gent: els nombres decimals en Java s'escriuen amb punt. Ho apuntem en el bloc d'errors i seguim.

I si volguérem saber quant es cobra en un mes (4 setmanes i mitja)? Quines línies hi afegiríem?

Mini exercicis

Activitats molt curtes: un minut o dos cada una.

1

La teua edat

Fàcil 1 min
Crea una variable int amb la teua edat i mostra-la amb un missatge.
Solució proposada 
public class LaMeuaEdat {
    public static void main(String[] args) {
        int edat = 16;
        System.out.println("Tinc " + edat + " anys.");
    }
}
Eixida per pantalla 
Tinc 16 anys.

Per què es fa aixina: Has declarat la variable amb el tipus (int), li has donat un valor i l'has mostrada eganxant-la al text.

2

Les vides que queden

Fàcil 2 min
Crea una variable per a les vides d'un jugador, que comença amb 3. Lleva-li una vida, mostra-la, lleva-li'n una altra i torna a mostrar-la.
Solució proposada 
public class Vides {
    public static void main(String[] args) {
        int vides = 3;
        System.out.println("Vides: " + vides);

        vides = vides - 1;
        System.out.println("Vides: " + vides);

        vides = vides - 1;
        System.out.println("Vides: " + vides);
    }
}
Eixida per pantalla 
Vides: 3
Vides: 2
Vides: 1

Per què es fa aixina: Sempre la mateixa variable: el que canvia és el valor de dins. Fixa't que la instrucció vides = vides - 1 es repetix dos vegades.

3

Un preu amb descompte

Fàcil 2 min
Un producte costa 80.0 euros i està rebaixat un 25 %. Calcula el preu final i mostra'l. Consell: un 25 % menys és multiplicar per 0.75.
Solució proposada 
public class Descompte {
    public static void main(String[] args) {
        double preu = 80.0;
        double preuFinal = preu * 0.75;

        System.out.println("Preu: " + preu + " euros");
        System.out.println("Preu amb descompte: " + preuFinal + " euros");
    }
}
Eixida per pantalla 
Preu: 80.0 euros
Preu amb descompte: 60.0 euros

Per què es fa aixina: Per aplicar un descompte es multiplica pel factor que queda. Un 25 % de descompte deixa el 75 % del preu: 0.75.

4

Què mostra este programa?

Intermèdia 2 min
Sense executar-lo, pensa què apareixerà per pantalla i explica per què. Després copia'l i comprova-ho.
int cites = 7;
int amics = 2;
System.out.println(cites / amics);
System.out.println(cites % amics);
Solució proposada 
int cites = 7;
int amics = 2;
System.out.println(cites / amics);   // 3
System.out.println(cites % amics);   // 1
Eixida per pantalla 
3
1

Per què es fa aixina: La divisió entre enters dona 3 (i es perd el 0.5). El residu diu quant sobra: 7 = 2 × 3 + 1, per tant sobra 1. Traduït al món real: 3 cites per persona i en sobra una.

5

Troba l'error

Intermèdia 3 min
Este programa no funciona. Copia'l, mira què diu el compilador i arregla'l.
public class Trencat {

        punts = 100;
        System.out.println(punts);
    }
}

Pista: El compilador es queixa que no troba cap símbol amb eixe nom. Quina informació li falta a Java per saber què és punts?

Solució proposada 
public class Arreglat {
    public static void main(String[] args) {
        int punts = 100;
        System.out.println(punts);
    }
}
Eixida per pantalla 
100

Per què es fa aixina: Faltava declarar la variable: Java no sabia si punts era un nombre, un text o què. Sense el tipus (int) no hi hauria ni una capsa on guardar el 100.

El teu nom pel teclat

Fàcil 3 min
Demana el nom a l'usuari (una sola paraula) i saluda'l pel seu nom.

Com ha de funcionar:

Exemple d'ús 
Quin és el teu nom? Ana
Què ha d'aparéixer 
Hola, Ana! Benvinguda al curs.
Solució proposada 
import java.util.Scanner;

public class Saluda {
    public static void main(String[] args) {
        Scanner teclat = new Scanner(System.in);

        System.out.print("Quin és el teu nom? ");
        String nom = teclat.next();

        System.out.println("Hola, " + nom + "! Benvinguda al curs.");
    }
}
Què ha de passar 
Quin és el teu nom? Ana
Hola, Ana! Benvinguda al curs.

Per què es fa aixina: next() llig una paraula (fins al primer espai) i la guarda en un String. Damunt et mostrem la sessió completa: el que escriu l'usuari i el que respon el programa.

import java.util.Scanner;

Fes el programa

Quatre exercicis una mica més llargs. Escriu-los sencers, executa'ls i prova'ls amb dades diferents abans de mirar la solució.

1

La fitxa personal

Fàcil 15 min
Demana a l'usuari el nom (una paraula), l'edat (un nombre enter) i l'alçada en metres (un nombre amb decimals). Després mostra una fitxa amb les tres dades.

Com ha de funcionar:

Exemple d'ús 
Nom: Ana
Edat: 16
Alçada (m): 1.63
Què ha d'aparéixer 
--- FITXA ---
Nom: Ana
Edat: 16 anys
Alçada: 1.63 m

Pista: Tres variables, tres mètodes del teclat: next(), nextInt() i nextDouble().

Solució proposada 
import java.util.Scanner;

public class Fitxa {
    public static void main(String[] args) {
        Scanner teclat = new Scanner(System.in);

        System.out.print("Nom: ");
        String nom = teclat.next();

        System.out.print("Edat: ");
        int edat = teclat.nextInt();

        System.out.print("Alçada (m): ");
        double alcada = teclat.nextDouble();

        System.out.println("--- FITXA ---");
        System.out.println("Nom: " + nom);
        System.out.println("Edat: " + edat + " anys");
        System.out.println("Alçada: " + alcada + " m");
    }
}
Què ha de passar 
Nom: Ana
Edat: 16
Alçada (m): 1.63
--- FITXA ---
Nom: Ana
Edat: 16 anys
Alçada: 1.63 m

Per què es fa aixina: Tres tipus distints per a tres dades distintes: String per al nom, int per a l'edat i double per a l'alçada. Podem llegir-los seguits sense problema perquè next(), nextInt() i nextDouble() salten els espais i els salts de línia.

2

La botiga de videojocs

Intermèdia 20 min
Una botiga ven claus de videojocs. Demana el preu en cèntims d'un joc i quants en vol comprar l'usuari. Calcula el total en cèntims i mostra'l també en euros (dividint entre 100.0).

Com ha de funcionar:

Exemple d'ús 
Preu en cèntims: 4999
Quants: 3
Què ha d'aparéixer 
Total: 14997 cèntims
En euros: 149.97 euros

Pista: Guarda els diners com a enters i dividix entre 100.0 només per mostrar. Compte a dividir entre 100 sense el .0.

Solució proposada 
import java.util.Scanner;

public class Botiga {
    public static void main(String[] args) {
        Scanner teclat = new Scanner(System.in);

        System.out.print("Preu en cèntims: ");
        int preuCentims = teclat.nextInt();

        System.out.print("Quants: ");
        int quantitat = teclat.nextInt();

        int totalCentims = preuCentims * quantitat;

        System.out.println("Total: " + totalCentims + " cèntims");
        System.out.println("En euros: " + totalCentims / 100.0 + " euros");
    }
}
Què ha de passar 
Preu en cèntims: 4999
Quants: 3
Total: 14997 cèntims
En euros: 149.97 euros

Per què es fa aixina: Els diners es guarden en cèntims (enters) perquè els int són exactes: així no hi ha sorpreses d'arrodoniment. Només en el moment de mostrar-los dividim entre 100.0 (amb el .0 perquè volem decimals!) per passar-ho a euros.

3

El conversor de temperatures

Intermèdia 20 min
Demana una temperatura en graus Celsius i mostra-la convertida a Fahrenheit. La fórmula és: Fahrenheit = Celsius × 9 / 5 + 32.

Com ha de funcionar:

Exemple d'ús 
Temperatura en Celsius: 30
Què ha d'aparéixer 
30.0 graus Celsius són 86.0 graus Fahrenheit.

Pista: Guarda la temperatura en un double encara que l'usuari escriga un nombre rodó.

Solució proposada 
import java.util.Scanner;

public class Conversor {
    public static void main(String[] args) {
        Scanner teclat = new Scanner(System.in);

        System.out.print("Temperatura en Celsius: ");
        double celsius = teclat.nextDouble();

        double fahrenheit = celsius * 9 / 5 + 32;

        System.out.println(celsius + " graus Celsius són " + fahrenheit + " graus Fahrenheit.");
    }
}
Què ha de passar 
Temperatura en Celsius: 30
30.0 graus Celsius són 86.0 graus Fahrenheit.

Per què es fa aixina: Com que celsius és double, tota la fórmula es calcula amb decimals: 30 × 9 = 270, dividit per 5 dona 54.0 i més 32, 86.0. Si hagueres guardat els graus en un int, la divisió per 5 et donaria un resultat fals en molts casos.

4

Quants entrepans puc comprar?

Cal pensar 25 min
Demana quants euros tens i quant costa un entrepà (les dos coses en euros enters). Digues quants entrepans pots comprar i quants euros et sobraran. No es pot emprar decimals ni condicions: només els operadors / i %.

Com ha de funcionar:

Exemple d'ús 
Euros que tens: 10
Preu de l'entrepà: 3
Què ha d'aparéixer 
Pots comprar 3 entrepans.
Et sobraran 1 euros.

Pista: La divisió entera et diu quants caben i el residu et diu què sobra. Prova-ho amb 10 i 3 a mà: 3 × 3 = 9, i en sobra 1.

Solució proposada 
import java.util.Scanner;

public class Entrepans {
    public static void main(String[] args) {
        Scanner teclat = new Scanner(System.in);

        System.out.print("Euros que tens: ");
        int diners = teclat.nextInt();

        System.out.print("Preu de l'entrepà: ");
        int preu = teclat.nextInt();

        int quants = diners / preu;      // divisió entera: només els sencers
        int sobren = diners % preu;      // el residu: el que no es pot gastar

        System.out.println("Pots comprar " + quants + " entrepans.");
        System.out.println("Et sobraran " + sobren + " euros.");
    }
}
Què ha de passar 
Euros que tens: 10
Preu de l'entrepà: 3
Pots comprar 3 entrepans.
Et sobraran 1 euros.

Per què es fa aixina: Ací la divisió entera és justament el que volem: 10 / 3 dona 3 perquè no es pot comprar mig entrepà. I el residu 10 % 3 dona 1, que són els euros que sobren. Dos operadors, dos resultats útils.

Reptes (sense solució)

🧠

Els reptes no tenen botó de solució, a propòsit. L'objectiu és pensar, provar, equivocar-se i tornar-ho a intentar. Es poden resoldre de moltes maneres diferents: totes les solucions que funcionen són bones.

REPTE 1

La fitxa del teu personatge

Crea un programa que construïsca la fitxa d'un personatge de videojoc. Ha de demanar el nom (una paraula), la classe (mag, guerrer, arquer…), els punts de vida i l'or que porta.

Després ha de calcular i mostrar: el nivell del personatge (cada 100 monedes d'or és un nivell) i quant or li falta per al següent nivell.

L'eixida ha de quedar com una fitxa, amb línies alineades i els valors ben col·locats. Pensa quines dades són enters i quines no.

Per anar més enllà:

  • Afig una dada més: el pes de l'equipament en quilograms (amb decimals) i mostra el pes total.
  • Que el programa calcule també la vida que li queda després de rebre un colp de 25 punts.
REPTE 2

La calculadora de l'índex de massa corporal

Fes un programa que demane el pes en quilograms (amb decimals) i l'alçada en metres (amb decimals) i calcule l'IMC, que es calcula així: IMC = pes / (alçada × alçada).

Mostra el resultat amb un missatge clar. Prova'l amb les teues dades i amb dades exagerades (2 metres d'alçada i 40 kg) i pensa si el resultat et pareix correcte.

No fa falta decidir si el resultat és bo o roín: això necessita condicions, i les condicions arriben en el següent tema. Ací només cal calcular i mostrar.

Per anar més enllà:

  • Que el programa mostre també quant pesaria la persona si guanyara 5 kg.
  • Afig la conversió de l'alçada a centímetres (alçada × 100).

Errors habituals

Estos són els errors que segur que veuràs. Llig-los abans de programar: quan apareguen, sabràs què passa.

Error 1

Usar una variable sense valor

Codi que falla 
int punts;
System.out.println(punts);

error: variable punts might not have been initialized

Què ha passat
Hem creat la caixa però l'hem deixada buida i després hem intentat mostrar què hi ha dins.
Per què
Java no suposa valors: una variable int no val 0 per art de màgia, i Java no vol inventar-se'n un.
Com detectar-ho
El missatge diu might not have been initialized («pot ser que no se li haja donat valor»).
Com corregir-ho
Dona-li un valor quan la declares: int punts = 0;. Si encara no saps quin valor tindrà, posa-li zero i canvia'l després.
Codi correcte 
int punts = 0;
System.out.println(punts);
Error 2

Escriure els decimals amb coma

Codi que falla 
double preu = 4,95;

error: ',' expected double preu = 4,95; ^

Què ha passat
Hem escrit la coma decimal que fem servir quan parlem i quan escrivim a mà.
Per què
En Java (i en la majoria de llenguatges de programació) el separador decimal és el punt. La coma té un altre significat: servix per separar coses.
Com detectar-ho
El missatge deia literalment ',' expected: Java esperava una coma en un altre lloc perquè no entén eixa.
Com corregir-ho
Escriu el punt: 4.95. I recorda-ho també quan l'usuari haja d'escriure decimals pel teclat: 1.63, no 1,63.
Codi correcte 
double preu = 4.95;
Error 3

La divisió entera que es mengen els decimals

Codi que falla 
int notes = 21;
double mitjana = notes / 3;
Què ha passat
Esperàvem 7.0 i el programa… sí, dona 7.0. Però si les notes hagueren sumat 22, hauria donat 7.0 també! (Perquè 22 / 3 = 7 en divisió entera i es perd el 0.333).
Per què
La divisió es decideix abans de guardar el resultat: si els dos nombres són enters, Java fa la divisió entre enters i llença la part decimal. Després ja no hi ha res a recuperar.
Com detectar-ho
El senyal és un resultat rarament rodó quan esperàvem decimals. Si el resultat sempre és un nombre enter quan no ho hauria de ser, mira els tipus.
Com corregir-ho
Fes que almenys un dels dos siga decimal: escriu 3.0, o guarda el numerador en una variable double des del principi.
Codi correcte 
int notes = 21;
double mitjana = notes / 3.0;
Error 4

Oblidar el tipus de la variable

Codi que falla 
punts = 100;

error: cannot find symbol punts = 100; ^ symbol: variable punts

Què ha passat
Hem intentat guardar un valor en una variable que no havíem creat.
Per què
Java necessita saber el nom i el tipus abans d'usar una variable. Si no la troba, diu que no coneix eixe símbol.
Com detectar-ho
El missatge diu cannot find symbol i assenyala el nom exacte que no troba.
Com corregir-ho
Declara-la abans: int punts = 100;. Si el nom està ben escrit, mira si l'has declarada dins d'una altra part del programa on no arriba.
Codi correcte 
int punts = 100;
Error 5

Escriure una lletra quan el programa espera un número

Codi que falla 
Scanner teclat = new Scanner(System.in);
int edat = teclat.nextInt();

Exception in thread "main" java.util.InputMismatchException at java.base/java.util.Scanner.throwFor(Scanner.java:939)

Què ha passat
L'usuari ha escrit una lletra o una paraula on el programa esperava un nombre.
Per què
nextInt() només sap llegir nombres enters. Si el que arriba no és un nombre, llança una excepció i el programa s'atura.
Com detectar-ho
El missatge conté InputMismatchException. També passa si escrivim els decimals amb coma en un nextDouble().
Com corregir-ho
De moment, assegura't d'escriure el tipus de dada que toca (un nombre enter, amb punt si és decimal). Més avant aprendrem a comprovar-ho perquè el programa no es tanque.
Codi correcte 
Scanner teclat = new Scanner(System.in);
System.out.print("Edat: ");
int edat = teclat.nextInt();   // i l'usuari escriu un número
Error 6

Confondre cometes dobles i simples

Codi que falla 
String resposta = 'sí';
char inicial = "A";

error: incompatible types: char cannot be converted to String String resposta = 'sí'; error: incompatible types: String cannot be converted to char char inicial = "A";

Què ha passat
Hem creuat les cometes: text amb cometes simples i caràcter amb cometes dobles.
Per què
char guarda un sol caràcter i va entre cometes simples; String guarda text i va entre cometes dobles. Són dos tipus distints.
Com detectar-ho
El missatge parla de char cannot be converted to String (o al revés).
Com corregir-ho
Text → cometes dobles ("sí"). Un sol caràcter → cometes simples ('A').
Codi correcte 
String resposta = "sí";
char inicial = 'A';

Resum visual

Les idees que has d'endur-te. Si pots explicar-les amb les teues paraules, el tema està apamat.

Una variable és una caixa amb nom on guardem un valor que pot canviar.

Per crear-la cal dir-ne el tipus i el nom: int punts = 100;.

Tipus bàsics: int (enters), double (decimals), boolean (sí/no), char (un caràcter) i String (text).

Els operadors són + - * / %. El residu % diu què sobra d'una divisió.

Si dividixes dos enters, Java perd els decimals: escriu 2.0 o guarda els nombres com a double.

Amb + s'enganxen text i variables. Compte: "Total: " + a + b no suma! Cal (a + b).

Scanner permet llegir el que l'usuari escriu: nextInt(), nextDouble(), next().

Els decimals s'escriuen amb punt i Java no posa zeros que no calen: mostra 20.0 i 4.2.

Autoavaluació

Nou preguntes. Pensa la resposta abans de mirar-la: si l'encertes, ja tens el tema controlat.

  1. Què és una variable?

    • Un text que es mostra per pantalla.
    • Una caixa amb un nom on guardem un valor que pot canviar.
    • Una ordre que repetix instruccions.
    Solució

    Resposta: b) Una caixa amb un nom on guardem un valor.

    La variable té un nom i un tipus, guarda un valor i podem canviar eixe valor tantes vegades com vulguem.

  2. Quin tipus faries servir per guardar la nota d'un examen que pot ser 7.5?

    • int
    • double
    • String
    Solució

    Resposta: b) double

    Un int no pot guardar decimals: 7.5 es convertiria en un error de compilació. La nota va en double.

  3. Què mostra este programa per pantalla?

    int vides = 3;
vides = vides + 2;
System.out.println("Vides: " + vides);
    Solució

    Resposta: Vides: 5

    La variable comença valent 3, després es guarda 3 + 2 = 5 en la mateixa variable i finalment es mostra.

  4. Quin és el resultat de 7 / 2 si els dos nombres són enters? I el de 7 % 2?

    Solució

    Resposta: 7 / 2 dona 3 i 7 % 2 dona 1.

    La divisió entre enters es queda amb la part entera i llenga els decimals. El residu (%) dona el que sobra: 7 = 2 × 3 + 1.

  5. Volem la mitjana de dos nombres enters que sumen 21 i volem decimals. Quina línia és correcta?

    • double m = 21 / 2;
    • double m = 21 / 2.0;
    • double m = 21 % 2;
    Solució

    Resposta: b) double m = 21 / 2.0;

    Amb 2.0 la divisió es fa amb decimals i el resultat és 10.5. En la primera opció, Java fa la divisió entre enters (10) i després guarda eixe 10 dins d'un double: ja és massa tard.

  6. Què apareixerà per pantalla?

    int a = 3;
int b = 4;
System.out.println("Total: " + a + b);
    Solució

    Resposta: Total: 34

    Quan el + ajunta un text amb un número, tot el que ve després es convertix en text i s'enganxa. Si volíem la suma, caldria escriure "Total: " + (a + b).

  7. Per què el programa s'atura amb InputMismatchException?

    Scanner teclat = new Scanner(System.in);
int edat = teclat.nextInt();
// l'usuari escriu: setze
    Solució

    Resposta: Perquè l'usuari ha escrit lletres on el programa esperava un nombre enter.

    nextInt() només llig nombres enters. També passa si escrius un decimal amb coma: Java espera el punt.

  8. Este programa no compila. Què li falta?

    mitjana = 7.5;
System.out.println(mitjana);
    Solució

    Resposta: Falta declarar la variable amb el seu tipus: double mitjana = 7.5;.

    Java ha de saber el nom i el tipus abans d'usar una variable. El missatge seria cannot find symbol: variable mitjana.

  9. Volem guardar l'edat d'una persona que pot tindre 15 anys o 15.5 anys (mig any). Quin tipus tries, i per què?

    Solució

    Resposta: double, perquè ha de poder guardar decimals.

    Si tries int i guardes 15.5, el programa ni tan sols compilarà. Pensar el tipus de cada dada abans d'escriure el codi ens estalvia errors: sempre ens preguntem «pot tindre decimals esta dada?».
