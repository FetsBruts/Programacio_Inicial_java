Tema 3 · Sessió de 3 hores

Repetir: els bucles

Escriure «Hola» cinc vegades és fàcil. Escriure'l 1.000 vegades, o comptar les notes de tota la classe, ja no. Per a això existeixen els bucles: la primera superpotència de veritat d'un programa.

⏱ 3 hores 📦 Fase 1 · Pensament de programador 🧩 Necessites: Temes 0, 1 i 2 ❓ La pregunta clau: quantes voltes, i quan pare?

Una situació per començar

🎮

Un videojoc mostra la paraula GAME OVER i fa un compte enrere: 3… 2… 1… Fins ara ho hauríem d'escriure així:

System.out.println("GAME OVER");
          System.out.println("3");
          System.out.println("2");
          System.out.println("1");
          System.out.println("Fi");
Eixida per pantalla 
GAME OVER
          3
          2
          1
          Fi

Funciona… per a un compte de 3. I si volem comptar des de 100? I si volem demanar la contrasenya fins que l'usuari l'encerta? No sabem quantes voltes farà! Escriure 100 línies no és programar.

Els programes de veritat no repeteixen codi: fan que el codi es repetisca. Esta és la idea d'este tema: el bucle (o bucle, en anglés loop).

30-40 min Explicació i demos
60-75 min Programació guiada
60-75 min Exercicis
15-30 min Repàs i repte
Abans de començar has de poder fer això:
  • Crear variables i canviar-ne el valor.
  • Llegir dades pel teclat amb Scanner.
  • Fer comparacions i escriure un if (Tema 2).

Què aprendrem en este tema?

En acabar esta sessió has de saber fer estes coses:

  • 1Escriure un bucle while amb la seua condició.
  • 2Escriure un bucle for quan sé quantes voltes vull.
  • 3Usar un comptador i un acumulador dins d'un bucle.
  • 4Saber quan s'acaba un bucle i per què (condició d'eixida).
  • 5Reconéixer un bucle infinit i arreglar-lo.
  • 6Triar entre while i for segons el problema.

Teoria, poc a poc

Una idea → un exemple. I dues preguntes sempre: quantes voltes fa? i quan para?

1. El bucle while

while significa «mentres». Es llig així: mentres la condició siga vertadera, repeteix el que hi ha dins de les claus.

public class Comptar {
            public static void main(String[] args) {
                int i = 1;

                while (i <= 5) {
                    System.out.println("Volta número " + i);
                    i = i + 1;
                }

                System.out.println("Fi. He contat fins a " + (i - 1));
            }
        }
Eixida per pantalla 
Volta número 1
        Volta número 2
        Volta número 3
        Volta número 4
        Volta número 5
        Fi. He contat fins a 5

Fixa't en les tres peces que sempre té un bucle:

  1. Una variable que canvia: i (es diu comptador).
  2. Una condició que al principi és vertadera: i <= 5.
  3. Una línia que acosta la condició a fer-se falsa: i = i + 1.
⛔

Si falta la tercera peça, el bucle no s'acaba mai. Eixe és el famós bucle infinit. El programa no dona cap error: es queda pensant per sempre i l'has de parar a la força.

2. Comptadors: i = i + 1

Un comptador és una variable que guarda quantes voltes hem fet. Es pot canviar de tres maneres:

S'escriuQuè faQuan el fem servir
i = i + 1suma 1 (es veu tot el procés)per entendre-ho
i++suma 1 (forma curta)és el més habitual
i--resta 1per comptar enrere
i = i + 2suma 2per anar de dos en dos
 
public class Coet {
            public static void main(String[] args) {
                int i = 3;

                while (i > 0) {
                    System.out.println(i);
                    i--;
                }

                System.out.println("Despeguem!");
            }
        }
Eixida per pantalla 
3
        2
        1
        Despeguem!
💡

La condició s'ha de llegir com un permís per continuar: i > 0. Quan arriba a 0, el permís desapareix i el bucle para. El valor que fa que pare es diu condició d'eixida.

3. Acumuladors: sumar dins del bucle

Un acumulador és una variable que va acumulant un valor a cada volta: una suma, un total de punts, un producte… És la base de tots els comptes que faràs en programació.

public class Suma {
            public static void main(String[] args) {
                int suma = 0;              // comença a zero, SEMPRE fora del bucle

                for (int i = 1; i <= 10; i++) {
                    suma = suma + i;
                }

                System.out.println("La suma del 1 al 10 és " + suma);
            }
        }
Eixida per pantalla 
La suma del 1 al 10 és 55

Comprovem-ho a mà: 1 + 2 + 3 + … + 10 = 55. El acumulador va guardant el total volta a volta: després de la primera 1, després 3, després 6, després 10, i aixina fins a 55.

⛔

L'acumulador s'inicialitza abans del bucle i s'actualitza dins. Un error clàssic és crear-lo dins del bucle: llavors es perd el total de cada volta i només guardarem l'últim valor.

4. El bucle for: quan sabem quantes voltes

Si sabem quantes voltes volem fer, hi ha una manera més curta i ordenada. El for té les tres peces del bucle escrites totes juntes al principi:

for (comença; mentre es complisca; què canvie en cada volta)

public class Taula {
            public static void main(String[] args) {
                int numero = 7;

                for (int i = 1; i <= 5; i++) {
                    int resultat = numero * i;
                    System.out.println(numero + " x " + i + " = " + resultat);
                }
            }
        }
Eixida per pantalla 
7 x 1 = 7
        7 x 2 = 14
        7 x 3 = 21
        7 x 4 = 28
        7 x 5 = 35

Compara'ls i veuràs que fan el mateix, però el for ho diu tot d'una vegada:

PreguntaAmb whileAmb for
On comença el comptador?int i = 1; (fora)for (int i = 1;
Quina és la condició?while (i <= 5); i <= 5;
Què canvia a cada volta?i++; (dins)i++)
Quant viu la variable i?Fins al final del programaNomés dins del bucle
💡

Regla pràctica: si sé quantes voltes → for. Si depén d'una condició que no controle (una contrasenya, una resposta de l'usuari) → while.

5. Bucles que depenen de l'usuari

Moltes vegades no sabem quantes voltes farem: depén del que faça l'usuari. Ací el while és el rei. Este programa demana la contrasenya fins que s'encerta:

import java.util.Scanner;

        public class ClauCorrecta {
            public static void main(String[] args) {
                Scanner teclat = new Scanner(System.in);
                String clau = "";

                while (!clau.equals("java2026")) {
                    System.out.print("Contrasenya: ");
                    clau = teclat.next();
                }

                System.out.println("Endavant, pots entrar!");
            }
        }
Què ha de passar 
Contrasenya: hola
        Contrasenya: 1234
        Contrasenya: java2026
        Endavant, pots entrar!

Fixa't que la variable clau es crea abans del bucle amb un text buit (""), perquè la condició puga comprovar-se la primera vegada.

ℹ️

Hem escrit !clau.equals("java2026"), que es llig «mentres la clau NO siga java2026». L'operador ! del tema anterior és molt útil en les condicions dels bucles.

6. Pistes per a l'usuari i break

Quan el bucle espera una resposta correcta, és molt important dir a l'usuari què està passant. I quan volem eixir d'un bucle enmig, tenim break: «ix del bucle ara mateix».

public class Divisor {
            public static void main(String[] args) {
                int numero = 31431;
                int divisor = 2;

                while (true) {
                    if (numero % divisor == 0) {
                        System.out.println("El divisor més menut és " + divisor);
                        break;      // ja el tenim: no cal seguir buscant
                    }
                    divisor = divisor + 1;
                }
            }
        }
Eixida per pantalla 
El divisor més menut és 3

while (true) significa «per sempre». El bucle para quan arriba al break. Este patró es fa servir molt: buscar alguna cosa fins a trobar-la i, quan la trobem, eixir.

⚠️

while (true) sense cap break és un bucle infinit segur. Si el fas servir, assegura't que hi ha almenys un camí que el puga aturar.

7. I si el bucle no fa cap volta?

El cos d'un bucle pot executar-se zero vegades. Depén sempre de la condició.

public class ZeroVoltes {
            public static void main(String[] args) {
                int i = 1;

                while (i > 10) {
                    System.out.println("Açò no s'escriu mai");
                    i++;
                }

                System.out.println("El programa continua normalment");
            }
        }
Eixida per pantalla 
El programa continua normalment
⚠️

Si el programa «no fa res» i esperaves que contara alguna cosa, mira bé la condició del bucle: pot ser que la primera comprovació ja siga falsa.

8. Bucles infinits: què fer

Si el teu programa es queda penjat i no acaba, probablement és un bucle infinit. No espantes: es para i es repara.

  • Per a parar-lo: en l'editor, botó de Stop (quadradet roig). A la terminal: Ctrl + C.
  • Sempre sol ser la mateixa causa: el comptador no canvia mai, o canvia en la direcció equivocada.

Este codi no acaba mai: falta la línia que canvia i. El pots escriure per vore-ho, però no l'executes: es queda penjat.

int i = 1;
        while (i <= 5) {
            System.out.println("Soc l'Infinito");
        }
⛔

Protocol sempre que un programa es penja: (1) para'l, (2) mira la condició, (3) mira si la variable de la condició canvia dins del bucle, (4) arregla-ho i torna a executar.

Exemples explicats pas a pas

Cada exemple: què volem aconseguir, el codi, què apareix per pantalla i per què funciona.

Exemple 1 · La suma de punts del joc

Què volem? Un joc fa 5 partides i dóna punts en cada una. Volem el total i la mitjana. Sense bucles, açò serien 5 nextInt() seguits.

import java.util.Scanner;

        public class Punts {
            public static void main(String[] args) {
                Scanner teclat = new Scanner(System.in);
                int total = 0;

                for (int partida = 1; partida <= 5; partida++) {
                    System.out.print("Punts de la partida " + partida + ": ");
                    int punts = teclat.nextInt();
                    total = total + punts;
                }

                double mitjana = total / 5.0;
                System.out.println("Total: " + total + " punts");
                System.out.println("Mitjana per partida: " + mitjana);
            }
        }
Què ha de passar 
Punts de la partida 1: 120
        Punts de la partida 2: 95
        Punts de la partida 3: 180
        Punts de la partida 4: 60
        Punts de la partida 5: 145
        Total: 600 punts
        Mitjana per partida: 120.0

Per què funciona: el comptador partida va de l'1 al 5. Cada volta llegim un valor i el sumem a total. Quan el bucle acaba, total té la suma de les cinc partides.

💡

Fixa't en el 5.0: dividir un int entre un int dona un int (i perdria els decimals). Com al tema 1: si volem decimals, almenys un dels dos valors ha de ser double.

Exemple 2 · Estalviar per al mòbil

Què volem? Cada setmana estalviem 15 €. Quantes setmanes calen per arribar a 100 €? No sabem el número de voltes: while.

public class Estalvi {
            public static void main(String[] args) {
                int diners = 0;
                int setmanes = 0;

                while (diners < 100) {
                    diners = diners + 15;
                    setmanes++;
                }

                System.out.println("Calen " + setmanes + " setmanes.");
                System.out.println("Al final tindrem " + diners + " euros.");
            }
        }
Eixida per pantalla 
Calen 7 setmanes.
        Al final tindrem 105 euros.

Per què funciona: el bucle seguix mentres no arribem als 100 €. Cada volta suma 15 € i augmenta el comptador. Al final, amb 105 €, la condició diners < 100 ja és falsa i el bucle para.

💡

Observa que ens passem de 100 €. Quan el que volem és passar un llindar, el bucle sempre acaba «una mica més enllà». Si vols el primer valor que supera el llindar, això mateix és el correcte.

Exemple 3 · Nota mitjana de la classe (sense arrays!)

Què volem? Saber quantes notes es van llegint i la seua mitjana, sense saber quantes n'hi haurà. Utilitzarem un valor especial per a acabar: el -1.

import java.util.Scanner;

        public class MitjanaClasse {
            public static void main(String[] args) {
                Scanner teclat = new Scanner(System.in);
                double suma = 0;
                int quantes = 0;

                System.out.print("Nota (-1 per acabar): ");
                double nota = teclat.nextDouble();

                while (nota != -1) {
                    suma = suma + nota;
                    quantes++;
                    System.out.print("Nota (-1 per acabar): ");
                    nota = teclat.nextDouble();
                }

                if (quantes > 0) {
                    System.out.println("Hi ha " + quantes + " notes.");
                    System.out.println("La mitjana és " + (suma / quantes));
                } else {
                    System.out.println("No has escrit cap nota.");
                }
            }
        }
Què ha de passar 
Nota (-1 per acabar): 6
        Nota (-1 per acabar): 7
        Nota (-1 per acabar): 4
        Nota (-1 per acabar): 9
        Nota (-1 per acabar): -1
        Hi ha 4 notes.
        La mitjana és 6.5

Per què funciona: llegim la primera nota abans del bucle i una més al final de cada volta. Quan arriba el -1, el bucle s'atura. El -1 es diu valor sentinella: un valor que no és una dada real i que només servix per a dir «ja està».

⚠️

Amb el sentinella hem de tindre compte de no sumar-lo mai: per això el comprovem abans d'entrar al cos del bucle. Si el sumarem, la mitjana estaria mal calculada.

Exemple 4 · Control de candidats a un portallengües

Què volem? Acceptar candidats per al portallengües de la classe, i parar quan un dels candidats no complisca el requisit de nota. Un for que es deté enmig amb break.

import java.util.Scanner;

        public class Portallengues {
            public static void main(String[] args) {
                Scanner teclat = new Scanner(System.in);
                int acceptats = 0;

                for (int candidat = 1; candidat <= 5; candidat++) {
                    System.out.print("Nota del candidat " + candidat + ": ");
                    double nota = teclat.nextDouble();

                    if (nota < 7) {
                        System.out.println("Candidat " + candidat + ": no passa el tall.");
                        break;
                    }

                    acceptats++;
                    System.out.println("Candidat " + candidat + ": acceptat!");
                }

                System.out.println("Candidats acceptats: " + acceptats);
            }
        }
Què ha de passar 
Nota del candidat 1: 9
        Candidat 1: acceptat!
        Nota del candidat 2: 8
        Candidat 2: acceptat!
        Nota del candidat 3: 6.5
        Candidat 3: no passa el tall.
        Candidats acceptats: 2

Per què funciona: el break fa que el bucle acabe immediatament. Les voltes 4 i 5 no es fan. I com que acceptats es va guardant fora de les decisions, al final tenim el compte correcte.

ℹ️

Fixa't que este programa no usa arrays: guardem el compte, no les notes. Sempre que pugues, guarda només el que necessites.

Quantes voltes es fan?

Llig el codi i pensa quantes línies apareixeran i amb quins números. Després comprova-ho.

Pensa abans d'executar

for (int i = 0; i < 6; i++) {
            if (i % 2 == 0) {
                System.out.println(i);
            }
        }
Resposta
Eixida real
0
        2
        4

Per què: El bucle fa 6 voltes (0, 1, 2, 3, 4, 5) perquè comença en 0 i la condició és i < 6. Dins, només s'escriuen els que tenen residu 0 en dividir per 2: el 0, el 2 i el 4. El 6 no entra perquè el bucle ja ha parat.

Programació guiada: ho fem junts

Farem el joc d'endevinar el número secret. Primer amb una sola pregunta, després amb el bucle, després amb pistes i finalment amb un límit d'intents.

1

El problema, en paraules

El programa pensa un número (del 1 al 100). L'usuari ha d'endevinar-lo. El programa ha de: preguntar, comprovar, donar una pista (*més gran* o més menut), tornar a preguntar, comptar els intents i felicitar quan s'encerta.

Sabem quantes voltes farà? Per què?

No ho sabem: l'usuari pot encertar-ho a la primera o necessitar huit intents. Per tant, while. I la condició serà «mentres la prova siga diferent del número secret».

2

Primera versió: una sola pregunta

Com sempre, comencem pel més simple possible: preguntem una vegada i comprovem. Encara sense bucle.

import java.util.Scanner;

          public class Endevinalla {
              public static void main(String[] args) {
                  Scanner teclat = new Scanner(System.in);
                  int secret = 42;

                  System.out.print("El meu número (1-100): ");
                  int prova = teclat.nextInt();

                  if (prova == secret) {
                      System.out.println("Correcte!");
                  } else {
                      System.out.println("No! Torna-ho a provar.");
                  }
              }
          }
Què ha de passar 
El meu número (1-100): 30
          No! Torna-ho a provar.
3

Afig el bucle while

Ara volem que torne a preguntar. Afegim el while: mentres la prova siga distint del secret, pregunta un'altra vegada.

import java.util.Scanner;

          public class Endevinalla {
              public static void main(String[] args) {
                  Scanner teclat = new Scanner(System.in);
                  int secret = 42;

                  System.out.print("El meu número (1-100): ");
                  int prova = teclat.nextInt();

                  while (prova != secret) {
                      System.out.print("No! Torna-ho a provar: ");
                      prova = teclat.nextInt();
                  }

                  System.out.println("Correcte! El número era el " + secret + ".");
              }
          }
Què ha de passar 
El meu número (1-100): 30
          No! Torna-ho a provar: 55
          No! Torna-ho a provar: 42
          Correcte! El número era el 42.

Per què hem hagut de canviar el if per un while? Què guanyem?

4

Ara donem pistes

Dir només «No!» és molt frustrant. Un bon programa ajuda l'usuari. Si la prova és menuda, el secret és més gran; si és major, el secret és més menut.

import java.util.Scanner;

          public class Endevinalla {
              public static void main(String[] args) {
                  Scanner teclat = new Scanner(System.in);
                  int secret = 42;

                  System.out.print("El meu número (1-100): ");
                  int prova = teclat.nextInt();

                  while (prova != secret) {
                      if (prova < secret) {
                          System.out.print("El meu és més gran. Torna-ho a provar: ");
                      } else {
                          System.out.print("El meu és més menut. Torna-ho a provar: ");
                      }
                      prova = teclat.nextInt();
                  }

                  System.out.println("Correcte! El número era el " + secret + ".");
              }
          }
Què ha de passar 
El meu número (1-100): 30
          El meu és més gran. Torna-ho a provar: 60
          El meu és més menut. Torna-ho a provar: 42
          Correcte! El número era el 42.

Fixa't que els if estan dins del bucle: cada volta es tornen a comprovar les pistes. Un if dins d'un bucle és el patró més habitual que existeix.

5

Comptem els intents i limitem-los a 5

Un joc sense límit és massa fàcil (o massa llarg). Afegim un comptador d'intents i parem als 5.

import java.util.Scanner;

          public class Endevinalla {
              public static void main(String[] args) {
                  Scanner teclat = new Scanner(System.in);
                  int secret = 42;
                  int intents = 0;
                  int prova = 0;

                  while (prova != secret && intents < 5) {
                      intents++;
                      System.out.print("Intent " + intents + ". El meu número (1-100): ");
                      prova = teclat.nextInt();

                      if (prova < secret) {
                          System.out.println("El meu és més gran que eixe.");
                      } else if (prova > secret) {
                          System.out.println("El meu és més menut que eixe.");
                      }
                  }

                  if (prova == secret) {
                      System.out.println("Correcte! Has encertat en " + intents + " intents.");
                  } else {
                      System.out.println("S'han acabat els intents. El número era el " + secret + ".");
                  }
              }
          }
Què ha de passar 
Intent 1. El meu número (1-100): 50
          El meu és més menut que eixe.
          Intent 2. El meu número (1-100): 20
          El meu és més gran que eixe.
          Intent 3. El meu número (1-100): 35
          El meu és més gran que eixe.
          Intent 4. El meu número (1-100): 42
          Correcte! Has encertat en 4 intents.

La condició del bucle ara té dos motius per parar: encertar o quedar-se sense intents. S'unixen amb &&: el bucle continua només si encara no s'ha encertat i queden intents.

I si no s'encerta mai? Provem-ho amb cinc números que fallen:

// Mateix programa de dalt, amb estes dades:
          // 1, 2, 3, 4, 5  →  cap coincidix amb el 42
Què ha de passar 
Intent 1. El meu número (1-100): 1
          El meu és més gran que eixe.
          Intent 2. El meu número (1-100): 2
          ...
          Intent 5. El meu número (1-100): 5
          El meu és més gran que eixe.
          S'han acabat els intents. El número era el 42.

Quina d'estes dos condicions s'examina primer: prova != secret o intents < 5? Passaria res si les canviem d'orde?

6

Proves finals i millores

Un programa no està acabat fins que el proves amb casos estranys. Estos són els d'este joc:

Què provesQuè ha de passar
Encertar a la primeraHa de dir «Has encertat en 1 intents»
Fallar cinc vegadesHa de dir el número i acomiadar-se
Un número fora de l'1-100El programa no avisa: això és una millora pendent
Escriure una lletraInputMismatchException (com en el tema 1)

I ací van tres millores que pots fer tu: comprovar que el número estiga entre 1 i 100, dir si la prova és molt lluny (*«fred!»*) o prop (*«calent!»*), i deixar que l'usuari trie la dificultat segons els intents.

💡

Millorar un programa que ja funciona és el millor exercici de programació que hi ha: no comences de zero i has d'entendre bé el que tens. Fes-ho sempre.

Mini exercicis

Activitats molt curtes per agafar soltura amb els bucles. Escriu-les i executa-les.

1

De l'1 al 5 amb while

Fàcil 3 min
Escriu un while que mostre els números de l'1 al 5, cadascun en una línia.
Solució proposada

import java.util.Scanner;

public class Guardiola {
    public static void main(String[] args) {
        Scanner teclat = new Scanner(System.in);

        System.out.print("Quant estalvies cada setmana? ");
        double setmanal = teclat.nextDouble();

        System.out.print("Quant vols aconseguir? ");
        double objectiu = teclat.nextDouble();

        if (setmanal <= 0) {
            System.out.println("Si no estalvies res, no avancem mai. Revisa les dades.");
        } else {
            double diners = 0;
            int setmanes = 0;

            while (diners < objectiu) {
                diners = diners + setmanal;
                setmanes++;
                System.out.println("Setmana " + setmanes + ": portes " + diners + " euros");
            }

            System.out.println("Has aconseguit l'objectiu en " + setmanes + " setmanes.");

            if (diners > objectiu) {
                System.out.println("T'has passat " + (diners - objectiu) + " euros.");
            } else {
                System.out.println("Has encertat just!");
            }
        }
    }
}

Errors habituals

Els errors habituals d'este tema. Hem classificat els perillosíssims (els que pengen el programa) i els lògics (els que donen un resultat equivocat).

Error 1

Oblidar d'incrementar el comptador → bucle infinit

Codi que falla 
int i = 1;
while (i <= 5) {
    System.out.println(i);
}
Què ha passat
El programa no acaba mai i ompli la pantalla de números 1.
Per què
La variable i de la condició no canvia mai. La condició i <= 5 sempre és vertadera i el bucle no té manera de parar.
Com detectar-ho
El programa no acaba, la pantalla no para de créixer i has de parar-lo amb el botó Stop o Ctrl + C.
Com corregir-ho
Assegura't que alguna cosa dins del bucle acosta la condició a fer-se falsa: i++. Regla: abans d'executar, llig el bucle i pregunta't «què farà que pare?».
Codi correcte 
int i = 1;
while (i <= 5) {
    System.out.println(i);
    i++;
}
Error 2

Punt i coma darrere del while (no dona error!)

Codi que falla 
int i = 1;
while (i <= 5);
{
    System.out.println(i);
    i++;
}
Què ha passat
El programa es queda penjat i no escriu res de res. I no dona cap error de compilació.
Per què
El ; deixa el while amb el cos buit: comprova la condició infinitament sense fer res, i mai no arriba a executar les claus de davall.
Com detectar-ho
Compila bé però no acaba ni mostra res. És el mateix parany que ja vam vore amb el if en el tema anterior.
Com corregir-ho
Lleva el ; de darrere de la condició. Norma pràctica: després de while (condició) sempre ve una clau {.
Codi correcte 
int i = 1;
while (i <= 5) {
    System.out.println(i);
    i++;
}
Error 3

Inicialitzar l'acumulador dins del bucle

Codi que falla 
for (int i = 1; i <= 5; i++) {
    int suma = 0;
    suma = suma + i;
    System.out.println(suma);
}
Què ha passat
En compte de 1, 3, 6, 10, 15, mostra 1, 2, 3, 4, 5. L'acumulador «s'oblida» del que havia sumat abans.
Per què
Si creem la variable dins del bucle, es torna a crear a cada volta amb el valor 0. No és un error de Java: és un error de disseny, i el programa compila perfectament.
Com detectar-ho
La suma final no és la que esperaves. Sempre sol ser un problema de on està creada la variable.
Com corregir-ho
Les variables que es volen guardar mentre el bucle roda es creen abans del bucle. Dins només s'actualitzen.
Codi correcte 
int suma = 0;
for (int i = 1; i <= 5; i++) {
    suma = suma + i;
    System.out.println(suma);
}
Error 4

Comptar una volta de més o de menys

Codi que falla 
for (int i = 1; i < 5; i++) {
    System.out.println("Volta " + i);
}
Què ha passat
El primer bucle fa 4 voltes quan en volem 5.
Per què
Amb < el número 5 no entra mai. Per comptar de l'1 al 5 inclòs, la condició ha de ser i <= 5.
Com detectar-ho
Compta les línies de l'eixida i compara-les amb les que esperaves. És l'error número u amb els bucles.
Com corregir-ho
Regla pràctica: si el comptador comença en 0, la condició és < N; si comença en 1, és <= N.
Codi correcte 
for (int i = 1; i <= 5; i++) {
    System.out.println("Volta " + i);
}
Error 5

Condició del while que ja és falsa de bon principi

Codi que falla 
int i = 1;
while (i > 10) {
    System.out.println(i);
    i++;
}
System.out.println("Açò s'escriu sempre");
Què ha passat
El programa no mostra ni un número i pareix que «no faça res».
Per què
La primera comprovació de la condició (1 > 10) ja és falsa, i el cos del bucle no s'executa mai.
Com detectar-ho
El programa acaba massa ràpid i sense eixida. Mira la condició i pensa si el primer valor la complix.
Com corregir-ho
Corregeix la condició perquè siga vertadera al principi. Si el bucle pot fer zero voltes i això és correcte, considera afegir un missatge per a l'usuari.
Codi correcte 
int i = 1;
while (i < 10) {
    System.out.println(i);
    i++;
}
System.out.println("Fi");
Error 6

Comparar textos amb == en la condició del bucle

Codi que falla 
String clau = "";
while (clau != "java") {
    System.out.print("Contrasenya: ");
    clau = teclat.next();
}
Què ha passat
El bucle no s'acaba mai, ni tan sols quan l'usuari escriu la contrasenya correcta. Bucle infinit.
Per què
Amb textos, != compara si són objectes diferents, i el text del teclat sempre és un objecte nou. Per això la condició és sempre vertadera.
Com detectar-ho
Demanes la contrasenya bé i el programa no reacciona: torna a preguntar sempre. Comparació de text + bucle = compte!
Com corregir-ho
Fes servir !clau.equals("java"). Els textos es comparen amb equals, dins i fora dels bucles.
Codi correcte 
String clau = "";
while (!clau.equals("java")) {
    System.out.print("Contrasenya: ");
    clau = teclat.next();
}

Resum visual

Les idees que has d'endur-te d'este tema.

Un bucle repetix codi: no escrivim mai el mateix mil vegades.

while repetix mentres la condició siga vertadera.

for és per quan sabem quantes voltes volem.

Tot bucle té tres peces: valor inicial, condició i canvi del comptador.

Sense el canvi del comptador → bucle infinit (Ctrl + C per a parar-lo).

Un comptador (i++) compta voltes; un acumulador (suma = suma + x) guarda totals.

Els acumuladors i comptadors es creen fora del bucle.

break servix per a eixir del bucle quan ja tenim el que buscàvem.

Un bucle pot fer zero voltes si la condició ja és falsa.

Autoavaluació

Nou preguntes. Pensa-les abans de mirar la solució.

  1. Quantes voltes fa este bucle?

    for (int i = 1; i <= 4; i++) {
    System.out.println(i);
}
    Solució

    Resposta: 4 voltes: s'escriuen 1, 2, 3 i 4.

    La condició és i <= 4, és a dir, fins a 4 inclòs. Comença en 1, així que fa 4 voltes.

  2. Quina diferència hi ha entre while i for?

    • No hi ha cap diferència, fan exactament el mateix codi.
    • for és per quan sabem quantes voltes volem; while, quan depén d'una condició.
    • while només servix per a comptar.
    Solució

    Resposta: b) for per a voltes conegudes i while per a condicions que no controlem.

    Els dos poden fer la mateixa faena, però el for ho diu tot en una línia (on comença, fins quan, com canvia). Quan sabem el número de voltes, queda més clar.

  3. Què és un bucle infinit?

    Solució

    Resposta: Un bucle del qual el programa no pot eixir mai perquè la seua condició no arriba a ser falsa.

    Normalment passa perquè falta canviar la variable de la condició. El programa compila bé, però es queda penjat: cal parar-lo amb el botó Stop o Ctrl + C.

  4. Este bucle no acaba mai. Per què?

    int i = 1;
while (i <= 3) {
    System.out.println(i);
}
    Solució

    Resposta: Falta i++ dins del bucle, així que i sempre val 1.

    La condició i <= 3 sempre és vertadera perquè i no canvia mai. Cal afegir la línia que incrementa el comptador perquè el bucle puga acabar.

  5. Escriu un bucle que sume els números de l'1 al 5 i mostre el total.

    Solució

    Resposta: int suma = 0; for (int i = 1; i <= 5; i++) { suma = suma + i; } System.out.println(suma);

    La variable suma és l'acumulador: es crea abans del bucle amb el valor 0 i dins del bucle va sumant el comptador. El resultat és 15.

  6. Quantes voltes fa este bucle i què s'escriu?

    int i = 2;
while (i < 10) {
    System.out.println(i);
    i = i + 2;
}
    Solució

    Resposta: Fa 4 voltes i s'escriuen 2, 4, 6 i 8.

    El comptador va de 2 en 2. Quan val 10, la condició i < 10 ja no es complix (el 10 no entra) i el bucle para. Per això no s'escriu el 10.

  7. Per què l'acumulador s'ha de crear fora del bucle?

    Solució

    Resposta: Perquè si es crea dins, es torna a posar a zero a cada volta i es perd el total acumulat.

    Una variable creada dins del bucle naix i mor en cada volta. Si volem recordar el total entre voltes, ha de nàixer abans i viure mentres el bucle treballa.

  8. Què fa exactament break dins d'un bucle?

    • Fa un descans d'un segon i continua.
    • Eix del bucle immediatament.
    • Torna a començar el bucle des del principi.
    Solució

    Resposta: b) Eix del bucle immediatament.

    Quan break s'executa, el bucle acaba i el programa continua en la línia següent, sense fer cap volta més. És molt útil per a buscar alguna cosa i parar quan la trobem.

  9. Volem demanar números fins que l'usuari escriga un 0, i sumar-los tots (el 0 no compta). Escriu el bucle.

    Solució

    Resposta: int suma = 0; int n = teclat.nextInt(); while (n != 0) { suma = suma + n; n = teclat.nextInt(); }

    El 0 és el valor sentinella: només indica que cal acabar. Per això la condició del bucle el detecta abans de sumar-lo. Si el sumàrem dins del bucle, el resultat seria incorrecte.
