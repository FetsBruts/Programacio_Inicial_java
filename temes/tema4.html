Tema 4 · Sessió de 3 hores

Arrays: guardar moltes dades

Trenta notes de classe no poden ser trenta variables. Un array és una fila de caselles numerades que es recorre amb un bucle: juntes, les dos idees del tema anterior i d'este es convertixen en una màquina de fer comptes.

⏱ 3 hores 📦 Fase 1 · Pensament de programador 🧩 Necessites: Temes 0 a 3 ❓ La pregunta clau: quina és la posició de cada dada?

Una situació per començar

📋

Volem un programa que demane les notes de sis companys i després diga la mitjana, la més alta, la més baixa i quantes persones han aprovat.

Amb el que sabem fins ara podríem fer-ho, però mira com queda:

double nota1 = 6.5;
          double nota2 = 4.0;
          double nota3 = 8.5;
          double nota4 = 5.0;
          double nota5 = 7.5;
          double nota6 = 3.5;

          // per a cada càlcul, una línia:
          double suma = nota1 + nota2 + nota3 + nota4 + nota5 + nota6;
          double mitjana = suma / 6;
          // i per al màxim i el mínim... quina faena!

I si foren 30 companys? I si foren 300? Este codi no s'aguanta. El problema és que cada dada necessita el seu propi nom, i nosaltres no podem inventar-se'n tants.

La solució és guardar totes les dades en una sola variable amb moltes caselles: un array. Cada casella té un número (la seua posició) i el bucle recorre totes les caselles una darrere l'altra.

Què aprendrem en este tema?

En acabar esta sessió has de saber fer estes coses:

  • 1Crear un array i saber quantes caselles té.
  • 2Guardar i llegir dades en una posició concreta.
  • 3Recórrer un array amb un for de la primera a l'última casella.
  • 4Calcular sumes, mitjanes, màxims i mínims d'un array.
  • 5Comptar i buscar valors dins d'un array.
  • 6Fer servir els mètodes útils dels textos (length, charAt, equals…).

Teoria, poc a poc

Una idea → un exemple. I una pregunta que no para: quina casella estic tocant ara?

1. Una fila de caselles

Un array (vector, en català) és una variable que guarda molts valors del mateix tipus, un darrere l'altre, i cada valor té un número de posició.

Pensa-ho com els calaixos d'una taula: el calaix 0, el calaix 1, el calaix 2… Es crea així:

int[] notes = new int[5];   // un array de 5 enters

        System.out.println("Té " + notes.length + " caselles");

        notes[0] = 7;      // guardem
        System.out.println(notes[0]);   // llegim
        System.out.println(notes[3]);   // encara no l'hem tocat: val 0
Eixida per pantalla 
Té 5 caselles
        7
        0

Tres coses importants:

  1. El tipus va amb claudàtors: int[] significa «array d'enters».
  2. new int[5] crea l'array amb 5 caselles.
  3. Les caselles d'un array de números comencen sempre amb el valor 0. No estan buides: valen 0.
int[] notes = new int[5];

        //  índex:    0    1    2    3    4
        //  valor:    0    0    0    0    0
        //           (5 caselles → índexs del 0 al 4)
⛔

La primera casella és la 0 i l'última és length - 1. Si l'array té 5 caselles, els índexs són 0, 1, 2, 3 i 4. El 5 no existix! És l'error més típic d'este tema.

2. Guardar amb la manera curta

Si ja sabem els valors des del principi, no cal crear l'array buit: es pot escriure directament entre claus.

int[] punts = {120, 95, 180, 60, 145};
        String[] noms = {"Ana", "Bruno", "Carla"};

        System.out.println(punts[2]);       // 180
        System.out.println(noms[0]);        // Ana
        System.out.println(punts.length);   // 5
Eixida per pantalla 
180
        Ana
        5
💡

Les dos maneres són igual de correctes. Si els valors els posa l'usuari, fem new int[quants]; si els escrivim nosaltres al codi, podem fer servir les claus.

3. Recórrer un array amb un for

Ací està la màgia: un array i un bucle encaixen perfectament. El comptador del bucle es convertix en l'índex de la casella.

public class Recorrer {
            public static void main(String[] args) {
                int[] punts = {120, 95, 180, 60, 145};

                for (int i = 0; i < punts.length; i++) {
                    System.out.println("Jugador " + (i + 1) + ": " + punts[i] + " punts");
                }
            }
        }
Eixida per pantalla 
Jugador 1: 120 punts
        Jugador 2: 95 punts
        Jugador 3: 180 punts
        Jugador 4: 60 punts
        Jugador 5: 145 punts

Llig-lo en veu alta: «per a i des de 0 mentres i siga menut que la quantitat de caselles, augmenta i». Dins s'accedix a punts[i], que va canviant de casella a cada volta.

I per què posem i + 1 en el missatge? Perquè l'índex 0 és el primer jugador, i als humans ens agrada comptar des de l'1. El programa compta des de 0, la pantalla des d'1.

⛔

La condició del bucle és i < array.length (menut, sense l'igual). Si escrius i <= array.length, quan i arribe a 5 buscaràs la casella 5 d'un array de 5 caselles i el programa fallarà.

4. La manera curta de recórrer: for-each

Quan volem tots els valors i no ens importa la posició, hi ha una manera més curta. Es diu for-each i es llig «per a cada».

public class ForEach {
            public static void main(String[] args) {
                String[] noms = {"Ana", "Bruno", "Carla"};

                // per a cada text (que direm nom) de la llista noms:
                for (String nom : noms) {
                    System.out.println(nom);
                }
            }
        }
Eixida per pantalla 
Ana
        Bruno
        Carla
Si…Fem servir
Necessite la posició (índex)for (int i = 0; i < a.length; i++)
Només vull els valorsfor (int valor : a)
Vull omplir l'array des del teclatfor amb índex, perquè cal assignar a a[i]
Vull modificar les casellesfor amb índex
ℹ️

El for-each només servix per a llegir. Amb ell no es pot guardar res en l'array, perquè no tenim el número de la casella.

5. Omplir un array des del teclat

El patró clàssic: el bucle demana una dada i la guarda directament en la casella.

import java.util.Scanner;

        public class Omplir {
            public static void main(String[] args) {
                Scanner teclat = new Scanner(System.in);
                double[] notes = new double[5];

                for (int i = 0; i < notes.length; i++) {
                    System.out.print("Nota " + (i + 1) + ": ");
                    notes[i] = teclat.nextDouble();
                }

                double suma = 0;
                for (int i = 0; i < notes.length; i++) {
                    suma = suma + notes[i];
                }

                System.out.println("Mitjana: " + (suma / notes.length));
            }
        }
Què ha de passar 
Nota 1: 6
        Nota 2: 7
        Nota 3: 6
        Nota 4: 9
        Nota 5: 8
        Mitjana: 7.2

Fixa't que hi ha dos bucles: un per a omplir i un altre per a calcular. Es podrien juntar, però separats es lligen millor i és el que fan quasi tots els programes de veritat.

6. Màxim i mínim: el mètode de l'aspirant

Volem saber el valor més gran d'un array. La idea: el primer element és el campió, i després cada altre valor li intenta prendre el títol.

public class MaxIMin {
            public static void main(String[] args) {
                int[] punts = {120, 95, 180, 60, 145};

                int maxim = punts[0];
                int minim = punts[0];

                for (int i = 1; i < punts.length; i++) {
                    if (punts[i] > maxim) {
                        maxim = punts[i];
                    }
                    if (punts[i] < minim) {
                        minim = punts[i];
                    }
                }

                System.out.println("La millor partida: " + maxim + " punts");
                System.out.println("La pitjor partida: " + minim + " punts");
            }
        }
Eixida per pantalla 
La millor partida: 180 punts
        La pitjor partida: 60 punts

Dos detalls que fan que funcione:

  1. El campió comença sent la primera casella (punts[0]), no 0 ni un número inventat.
  2. El bucle comença en i = 1, perquè la casella 0 ja l'hem mirada en inicialitzar.
⚠️

Si inicialitzes el màxim a 0 i tots els valors de l'array foren negatius (per exemple temperatures d'un congelador), el programa diria que el màxim és 0, i seria mentida. Per això comencem sempre amb array[0].

7. Buscar un valor dins de l'array

Buscar costa el mateix: recórrer i preguntar. Quan el trobem, guardem la posició i podem parar amb break.

public class Buscar {
            public static void main(String[] args) {
                String[] noms = {"Ana", "Bruno", "Carla", "Dani"};
                String buscat = "Carla";

                boolean trobat = false;

                for (int i = 0; i < noms.length; i++) {
                    if (noms[i].equals(buscat)) {
                        System.out.println("Trobat a la posició " + i);
                        trobat = true;
                        break;
                    }
                }

                if (!trobat) {
                    System.out.println("No està a la llista");
                }
            }
        }
Eixida per pantalla 
Trobat a la posició 2

El patró de la variable bandera: comença false, es posa true quan trobem el que busquem. Al final, mirem la bandera per saber què ha passat.

8. El text també és una fila de caràcters

Un String es comporta molt paregut a un array: cada posició és una lletra (un char). Per a treballar amb textos, hi ha unes quantes ferramentes que has de conéixer.

public class Ferramentes {
            public static void main(String[] args) {
                String text = "Programar en Java";

                System.out.println(text.length());            // quantes lletres? (amb parèntesis!)
                System.out.println(text.charAt(0));           // la lletra de la posició 0
                System.out.println(text.toUpperCase());       // tot en majúscules
                System.out.println(text.toLowerCase());       // tot en minúscules
                System.out.println(text.substring(0, 9));     // un tros: de la 0 a la 9 (la 9 no entra)
                System.out.println(text.contains("Java"));    // conté este tros?
                System.out.println(text.indexOf("Java"));     // en quina posició està?
            }
        }
Eixida per pantalla 
17
        P
        PROGRAMAR EN JAVA
        programar en java
        Programar
        true
        13

La llista de les més útils, per a tindre-la a mà:

S'escriuFaExemple
text.length()quantes lletres té (amb parèntesis)"Hola".length() → 4
text.charAt(2)la lletra de la posició 2"Hola".charAt(2) → l
text.equals(altre)si diuen exactament el mateix"Hola".equals("hola") → false
text.equalsIgnoreCase(altre)sense importar majúscules"Hola".equalsIgnoreCase("hola") → true
text.substring(a, b)el tros de la posició a a la b (sense incloure b)"Hola".substring(1, 3) → ol
text.toUpperCase()tot en majúscules"Hola".toUpperCase() → HOLA
text.contains("ol")si conté este tros"Hola".contains("ol") → true

⛔

length en un array, length() en un text. Són parents però no són iguals: l'array guarda el seu número de caselles en una propietat sense parèntesis, i el text t'ho diu amb un mètode amb parèntesis. Confondre-ho dona un error de compilació.

9. Veure un array sencer d'una vegada

Si intentes mostrar un array sencer, apareix una cosa rara. Prova-ho:

int[] punts = {120, 95, 180};
        System.out.println(punts);      // què és eixe text estrany?
Eixida per pantalla 
[I@1b6d3586

Eixe [I@1b6d3586 no són els teus números: és la «matrícula» de l'array en la memòria. Per a vore el contingut hi ha una ferramenta de Java que fa la faena:

import java.util.Arrays;

        public class AmbArrays {
            public static void main(String[] args) {
                int[] punts = {120, 95, 180};
                System.out.println(Arrays.toString(punts));
            }
        }
Eixida per pantalla 
[120, 95, 180]
💡

Arrays.toString(...) és una utilíssima de Java. De moment no necessitem entendre aquesta part (import, java.util, els punts…); ja arribarem a ella més avant. Per ara, copia-la tal qual quan vulgues vore un array sencer en una prova.

Exemples explicats pas a pas

Cada exemple: què volem aconseguir, el codi, què apareix per pantalla i per què funciona.

Exemple 1 · Les temperatures de la setmana

Què volem? Les temperatures dels 7 dies, la mitjana i si ha fet fred o calor.

public class Temperatures {
            public static void main(String[] args) {
                double[] temp = {21.5, 23.0, 19.5, 25.0, 27.5, 24.0, 22.5};

                double suma = 0;
                for (int i = 0; i < temp.length; i++) {
                    suma = suma + temp[i];
                    System.out.println("Dia " + (i + 1) + ": " + temp[i] + " graus");
                }

                double mitjana = suma / temp.length;
                System.out.println("Temperatura mitjana: " + mitjana + " graus");
            }
        }
Eixida per pantalla 
Dia 1: 21.5 graus
        Dia 2: 23.0 graus
        Dia 3: 19.5 graus
        Dia 4: 25.0 graus
        Dia 5: 27.5 graus
        Dia 6: 24.0 graus
        Dia 7: 22.5 graus
        Temperatura mitjana: 23.285714285714285 graus

Per què funciona: el bucle recorre les set caselles. Dins fem dos treballs alhora: sumar a l'acumulador i mostrar el dia, perquè el bucle només passa una vegada per davall.

💡

Eixe 23.285714285714285 es llig fatal. Mès avant aprendrem a arredonir-ho, però tu ja pots deixar-ho bonic: Math.round(mitjana * 100) / 100.0 el deixa amb dos decimals. Prova-ho!

Exemple 2 · Quants han superat la mitjana?

Què volem? Saber quants alumnes estan per damunt de la mitjana de la classe. Cal recórrer l'array dues vegades: primer per a calcular la mitjana, després per a comptar.

public class PerDamunt {
            public static void main(String[] args) {
                double[] notes = {5.5, 8.0, 4.5, 9.0, 6.5, 3.0, 7.0};

                double suma = 0;
                for (int i = 0; i < notes.length; i++) {
                    suma = suma + notes[i];
                }
                double mitjana = suma / notes.length;

                int perDamunt = 0;
                for (int i = 0; i < notes.length; i++) {
                    if (notes[i] > mitjana) {
                        perDamunt++;
                    }
                }

                System.out.println("Mitjana de la classe: " + mitjana);
                System.out.println("Per damunt de la mitjana: " + perDamunt + " alumnes");
            }
        }
Eixida per pantalla 
Mitjana de la classe: 6.214285714285714
        Per damunt de la mitjana: 4 alumnes

Per què funciona: hi ha dos recorreguts. El primer només acumula (no podem comparar amb la mitjana abans de conéixer-la). El segon compara cada nota amb eixa mitjana i les compta.

ℹ️

Alguna cosa més gran que 6,21 és 8, 9, 6.5 i 7: quatre alumnes. Comprovem que el programa diu el mateix... i sí, diu 4. Comprovar a mà el que ha de donar el programa és el que separa un programador d'algú que escriu codi i espera que passe.

Exemple 3 · Comptar vocals d'una paraula

Què volem? Dir quantes vocals té una paraula. Un text és una fila de lletres, així que es recorre igual que un array.

public class Vocals {
            public static void main(String[] args) {
                String paraula = "videoconsola";
                int vocals = 0;

                for (int i = 0; i < paraula.length(); i++) {
                    char lletra = paraula.charAt(i);

                    if (lletra == 'a' || lletra == 'e' || lletra == 'i' || lletra == 'o' || lletra == 'u') {
                        vocals++;
                    }
                }

                System.out.println("La paraula " + paraula + " té " + vocals + " vocals.");
            }
        }
Eixida per pantalla 
La paraula videoconsola té 6 vocals.

Per què funciona: anàlisi de videoconsola → v-i-d-e-o-c-o-n-s-o-l-a = 6 vocals. Cada lletra es compara amb les cinc vocals. Com que char es compara amb == (és un caràcter simple, no un text), ací sí podem fer servir ==.

💡

Les lletres simples (tipus char) es comparen amb == i van entre cometes simples: 'a'. Els textos van entre cometes dobles i es comparen amb equals. Una cometa, un caràcter; dos cometes, un text.

Exemple 4 · Quantes vegades apareix cada nota

Què volem? Comptar quantes vegades apareix un valor dins d'un array. Recorreguem l'array sencer i comptem les coincidències, sense parar.

public class Repeticions {
            public static void main(String[] args) {
                int[] daus = {3, 5, 3, 1, 3, 6, 5};
                int buscat = 3;
                int vegades = 0;

                for (int i = 0; i < daus.length; i++) {
                    if (daus[i] == buscat) {
                        vegades++;
                    }
                }

                System.out.println("El " + buscat + " ha eixit " + vegades + " vegades.");
            }
        }
Eixida per pantalla 
El 3 ha eixit 3 vegades.

Per què funciona: ací no hi ha break, perquè volem comptar-les totes. En l'exemple de buscar un nom sí que en tenia, perquè només ens interessava el primer que apareixia. La pregunta és sempre: «quan tinga el resultat, he de seguir mirant?»

Quantes voltes fa i què suma?

Llig el codi amb atenció i pensa el resultat abans d'executar-lo.

Pensa abans d'executar

int[] numeros = {4, 8, 15, 16};
        int suma = 0;

        for (int i = 1; i < numeros.length; i++) {
            suma = suma + numeros[i];
        }

        System.out.println(suma);
Resposta
Eixida real
39

Per què: El bucle comença en i = 1, no en 0! Per tant no suma el 4. Els valors sumats són 8 + 15 + 16 = 39. És el mateix patró que hem fet servir per al màxim i el mínim, on el primer element es mira fora del bucle.

Programació guiada: ho fem junts

Farem el rànquing d'un torneig de videojocs: cinc jugadors, els seus punts, el total, el millor, el pitjor i qui està per damunt de la mitjana.

1

El problema i les dades

Tenim 5 jugadors amb estos punts: 120, 95, 180, 60 i 145. Volem vore el rànquing, el total, la mitjana, el millor i el pitjor, i quants jugadors superen la mitjana.

Quantes caselles necessita l'array i quin serà l'índex de l'última?

Cinc caselles → índexs del 0 al 4. I com que no hi ha noms de jugadors, els direm Jugador 1 … Jugador 5 sumant 1 a l'índex.

2

Primer: mostrar el rànquing

Com sempre, comencem pel més simple: crear l'array i mostrar-lo numerat.

public class Ranking {
              public static void main(String[] args) {
                  int[] punts = {120, 95, 180, 60, 145};

                  for (int i = 0; i < punts.length; i++) {
                      System.out.println("Jugador " + (i + 1) + ": " + punts[i] + " punts");
                  }
              }
          }
Eixida per pantalla 
Jugador 1: 120 punts
          Jugador 2: 95 punts
          Jugador 3: 180 punts
          Jugador 4: 60 punts
          Jugador 5: 145 punts
💡

Prova de canviar i < punts.length per i <= punts.length i executa-ho. Veuràs l'error més típic dels arrays. Després torna-ho a deixar bé.

3

Total i mitjana

Ara afegim un acumulador. Podem calcular-ho tot en el mateix bucle de mostrar, però ho fem en un de nou per vore-ho clar.

public class Ranking {
              public static void main(String[] args) {
                  int[] punts = {120, 95, 180, 60, 145};

                  for (int i = 0; i < punts.length; i++) {
                      System.out.println("Jugador " + (i + 1) + ": " + punts[i] + " punts");
                  }

                  int total = 0;
                  for (int i = 0; i < punts.length; i++) {
                      total = total + punts[i];
                  }

                  System.out.println("Total del torneig: " + total + " punts");
                  System.out.println("Mitjana per jugador: " + (total / (double) punts.length) + " punts");
              }
          }
Eixida per pantalla 
Jugador 1: 120 punts
          Jugador 2: 95 punts
          Jugador 3: 180 punts
          Jugador 4: 60 punts
          Jugador 5: 145 punts
          Total del torneig: 600 punts
          Mitjana per jugador: 120.0 punts

La divisió porta (double) davant: convertix la quantitat de jugadors en un número decimal perquè la mitjana no perda els decimals.

💡

.length és un int. Si dividim int / int, Java dona un int (i perdríem els decimals). El (double) convertix el valor a decimal. De moment no cal entendre aquesta part a fons; queda't amb la idea: quan dividisques, assegura't que un dels dos costats és decimal.

4

El millor i el pitjor

Apliquem el mètode de l'aspirant: el primer jugador és el campió provisional i tots els altres li intenten prendre el títol.

public class Ranking {
              public static void main(String[] args) {
                  int[] punts = {120, 95, 180, 60, 145};

                  int maxim = punts[0];
                  int minim = punts[0];

                  for (int i = 1; i < punts.length; i++) {
                      if (punts[i] > maxim) {
                          maxim = punts[i];
                      }
                      if (punts[i] < minim) {
                          minim = punts[i];
                      }
                  }

                  System.out.println("Millor jugador: " + maxim + " punts");
                  System.out.println("Pitjor jugador: " + minim + " punts");
              }
          }
Eixida per pantalla 
Millor jugador: 180 punts
          Pitjor jugador: 60 punts

Per què el bucle comença en 1 i no en 0?

5

Quants jugadors superen la mitjana

Este és el càlcul de dos passades: primer la mitjana (ja el tenim) i després un bucle que compta.

public class Ranking {
              public static void main(String[] args) {
                  int[] punts = {120, 95, 180, 60, 145};

                  int total = 0;

Reptes (sense solució)

🧠

Els reptes no tenen botó de solució, a propòsit. L'objectiu és pensar, provar, equivocar-se i tornar-ho a intentar. Es poden resoldre de moltes maneres diferents: totes les solucions que funcionen són bones.

REPTE 1

La llista de la compra

Crea un array de 10 textos per als productes de la compra. El programa demana productes fins que l'usuari escriu fi o fins que s'ompliga l'array. Al final ha de mostrar la llista numerada i dir quants productes hi ha.

El repte és que no saps quants productes escriurà l'usuari: necessites una variable que compte quants n'has guardat, comprovar que no t'has passat de l'última casella i usar eixa variable com a condició del bucle.

Pregunta't: què ha de passar si l'usuari vol afegir un producte número 11? I si escriu directament fi sense res més?

Per anar més enllà:

  • Comprovar que el producte no estiga ja a la llista abans d'afegir-lo.
  • Permetre esborrar un producte pel seu número (idea: desplaçar els següents una casella cap arrere).
  • Mostrar la llista en orde alfabètic... amb les ferramentes que encara no coneixem, no es pot. Guarda-ho per al Tema 6.
REPTE 2

L'histograma dels daus

Guarda en un array les 12 tirades d'un dau i, després, compta quantes vegades ha eixit cada valor de l'1 al 6. El resultat ha de ser un histograma: per a cada valor, una línia amb tantes estrelletes com vegades ha eixit.

Exemple del que volem: 1: ** vol dir que l'1 ha eixit dos vegades. El truc és que les tirades d'un valor sempre estaran entre 1 i 6: si l'array de comptadors té 7 caselles, la tirada 3 es compta en comptadors[3] sense cap if.

Pensa primer com ompliries l'array de comptadors sense cap if, i després com faries les estrelletes (un bucle dins d'un altre).

Per anar més enllà:

  • Que les tirades les genere el programa (per exemple, amb (int) (Math.random() * 6) + 1).
  • Mostrar el percentatge de cada valor amb un decimal.
  • Fer el dibuix amb barres de # de llargària proporcional al número de tirades.

Errors habituals

Els errors d'este tema són molt fàcils de detectar si saps què buscar: quasi tots parlen de posicions.

Error 1

Buscar una casella que no existix

Codi que falla 
int[] notes = new int[5];
notes[0] = 7;
System.out.println(notes[5]); // no existix!
Què ha passat
El programa compila bé, però en executar-lo es para i mostra un missatge llarg amb ArrayIndexOutOfBoundsException.
Per què
L'array té 5 caselles amb índexs del 0 al 4. La casella 5 no existix, i Java no et deixa accedir a memòria que no és teua.
Com detectar-ho
Exception in thread "main" java.lang.ArrayIndexOutOfBoundsException: Index 5 out of bounds for length 5: el missatge diu ben clar quin índex havies demanat i quantes caselles hi ha.
Com corregir-ho
L'última casella d'un array és sempre array.length - 1. Si necessites un número fix, comprova que estiga dins del rang.
Codi correcte 
int[] notes = new int[5];
notes[0] = 7;
System.out.println(notes[4]); // l'última és length - 1
Error 2

Recórrer fins a length inclòs (i <= length)

Codi que falla 
int[] notes = {5, 6, 7, 8};
int suma = 0;

for (int i = 0; i <= notes.length; i++) {  // ERROR
    suma = suma + notes[i];
}
Què ha passat
El programa suma les quatre notes correctament… i després es para amb ArrayIndexOutOfBoundsException: Index 4 out of bounds for length 4.
Per què
Amb <= el bucle fa una volta de més: i arriba a valdre el número de caselles, i eixa casella no existix.
Com detectar-ho
El programa funciona bé durant un moment i falla just al final. Si l'error apareix després d'un resultat correcte, quasi sempre és un <= que hauria de ser <.
Com corregir-ho
Per a recórrer arrays, la condició correcta és i < array.length. Memoritza-ho com una fórmula.
Codi correcte 
int[] notes = {5, 6, 7, 8};
int suma = 0;

for (int i = 0; i < notes.length; i++) {
    suma = suma + notes[i];
}
Error 3

length amb parèntesis en un array

Codi que falla 
int[] notes = new int[5];
int quants = notes.length();
System.out.println(quants);

error: Cannot invoke length() on the array type int[] int quants = notes.length(); ^^^^^^^^^^^^^^

Què ha passat
El programa no compila.
Per què
En un array, length és una dada que ja porta dins (sense parèntesis). Els parèntesis són per als mètodes, i el text (String) sí que té un mètode length().
Com detectar-ho
El missatge diu Cannot invoke length() on the array type int[]. També passa al revés: escriure text.length en un text dona length cannot be resolved or is not a field.
Com corregir-ho
Regla: array → length (sense parèntesis); text → length() (amb parèntesis).
Codi correcte 
int[] notes = new int[5];
int quants = notes.length;
System.out.println(quants);
Error 4

Crear l'array sense new

Codi que falla 
int[] notes;
notes[0] = 5;
System.out.println(notes[0]);

error: The local variable notes may not have been initialized notes[0] = 5; ^^^^^ (2 errors)

Què ha passat
El programa no compila i assenyala la línia on guardem el valor.
Per què
int[] notes; només diu «este nom serà un array d'enters», però no crea les caselles. Sense new, no hi ha res on guardar.
Com detectar-ho
El missatge parla de «may not have been initialized» (pot ser que no s'haja inicialitzat).
Com corregir-ho
Cal crear l'array: int[] notes = new int[5]; (o omplir-lo directament amb {...}).
Codi correcte 
int[] notes = new int[5];
notes[0] = 5;
System.out.println(notes[0]);
Error 5

Mostrar l'array sencer amb un println

Codi que falla 
int[] punts = {120, 95, 180};
System.out.println(punts);
Què ha passat
En compte dels números, apareix una cosa estranya com [I@1b6d3586.
Per què
println no sap recórrer arrays: el que escriu és la «matrícula» interna de l'objecte. No és un error del programa, però no és el que volem.
Com detectar-ho
Eixida que comença per [ i porta una @ amb números i lletres. Si vas de pressa ni ho notes!
Com corregir-ho
O bé fas un bucle per a mostrar cada casella, o bé uses System.out.println(Arrays.toString(array)) per a vore-ho tot d'una vegada.
Codi correcte 
import java.util.Arrays;

int[] punts = {120, 95, 180};
System.out.println(Arrays.toString(punts)); // [120, 95, 180]
Error 6

Numerar els missatges amb l'índex directament

Codi que falla 
String[] noms = {"Ana", "Bruno", "Carla"};

for (int i = 0; i < noms.length; i++) {
    System.out.println(i + " - " + noms[i]); // mostra «0 - Ana»
}
Què ha passat
El programa funciona, però la llista comença en «0 - Ana» i als usuaris els pareix un error.
Per què
L'índex intern comença en 0, però les persones comptem des d'1. El programa no està mal: està mal explicat a l'usuari.
Com detectar-ho
Ho veus directament en l'eixida quan el primer element és el 0. És un error de presentació, no de càlcul.
Com corregir-ho
Suma 1 en el missatge: (i + 1). I recorda't que noms[i] no canvia: la casella seguix sent la i.
Codi correcte 
String[] noms = {"Ana", "Bruno", "Carla"};

for (int i = 0; i < noms.length; i++) {
    System.out.println((i + 1) + " - " + noms[i]); // «1 - Ana»
}

Resum visual

Les idees que has d'endur-te d'este tema.

Un array guarda molts valors del mateix tipus en caselles numerades.

Es crea amb new: int[] notes = new int[5]; (5 caselles) o amb {...}.

Els índexs van del 0 fins a length - 1. El primer és el 0!

Es recorre amb un for: for (int i = 0; i < array.length; i++).

El for-each (for (int x : array)) servix per a llegir-ho tot sense índex.

Array i bucle junts: sumes, mitjanes, màxims, mínims, comptadors i cerques.

El màxim i el mínim comencen en array[0] i el bucle comença en 1.

Els textos també es recorren: length(), charAt(i), substring, equals, contains.

array.length sense parèntesis; text.length() amb parèntesis.

Autoavaluació

Nou preguntes. Pensa-les abans de mirar la solució.

  1. Quantes caselles té int[] notes = new int[6]; i quin és l'índex de l'última?

    Solució

    Resposta: Té 6 caselles i l'última és l'índex 5.

    El número entre claudàtors és la quantitat de caselles. Com que els índexs comencen en 0, les caselles són 0, 1, 2, 3, 4 i 5: la última és length - 1.

  2. Amb quin índex s'accedix a la primera casella d'un array?

    • Amb l'1
    • Amb el 0
    • Depén de com s'haja creat
    Solució

    Resposta: b) Amb el 0.

    En Java (i en quasi tots els llenguatges) la primera posició d'un array és la 0. Per això, per a mostrar la llista a persones, sumem 1 en el missatge.

  3. Què mostra este codi?

    int[] edats = {14, 15, 16};
System.out.println(edats.length);
System.out.println(edats[1]);
    Solució

    Resposta: Mostra 3 i 15.

    edats.length és 3 (les tres caselles) i edats[1] és la segona casella, perquè la primera és la 0. Este segon detall és el que més costa al principi.

  4. Com s'escriu correctament el bucle per recórrer un array de nom notes?

    • for (int i = 0; i <= notes.length; i++)
    • for (int i = 0; i < notes.length; i++)
    • for (int i = 1; i <= notes.length; i++)
    Solució

    Resposta: b) for (int i = 0; i < notes.length; i++)

    L'índex comença a 0 i ha d'arribar fins a length - 1: per això la condició és < (menut), no <=. La tercera opció es deixaria la primera casella i es passaria de la última.

  5. Este codi falla en executar-se. Per què?

    int[] notes = {5, 6, 7, 8};
int suma = 0;

for (int i = 0; i <= notes.length; i++) {
    suma = suma + notes[i];
}
    Solució

    Resposta: Perquè el bucle intenta llegir la casella 4, que no existix (l'array va de la 0 a la 3).

    Amb <= el bucle fa una volta de més. Apareix ArrayIndexOutOfBoundsException: Index 4 out of bounds for length 4. La condició correcta és i < notes.length.

  6. Per què el màxim d'un array s'inicialitza amb array[0] i no amb 0?

    Solució

    Resposta: Perquè si tots els valors de l'array foren negatius (per exemple temperatures sota zero), el 0 seria un resultat fals.

    El primer element sempre és un valor real de l'array, així que servix de campió provisional sempre. Començar amb 0 dona resultats incorrectes amb arrays de números negatius.

  7. Escriu el codi que compta quantes notes d'un array notes estan aprovades (5 o més).

    Solució

    Resposta: int aprovats = 0; for (int i = 0; i < notes.length; i++) { if (notes[i] >= 5) { aprovats++; } }

    El comptador es crea abans del bucle i s'incrementa només quan es complix la condició. Sense break: volem comptar-les totes.

  8. Este codi compila? Per què?

    int[] notes = new int[5];
int quants = notes.length();
    Solució

    Resposta: No compila: en un array, length va sense parèntesis.

    El missatge és Cannot invoke length() on the array type int[]. Els parèntesis són per al length() del text (String). Array = length; text = length().

  9. Què fa charAt(2) sobre el text "Hola" i per què no es pot fer servir == per a comparar textos complets?

    Solució

    Resposta: charAt(2) torna l (la tercera lletra, perquè es comença a comptar en 0). Els textos complets es comparen amb equals perquè amb == es compara si són el mateix objecte, no si diuen el mateix.

    Cada posició d'un text és un char, i els char sí que es comparen amb == perquè són lletres simples. Els String són objectes i necessiten equals.
