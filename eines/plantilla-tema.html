Títol del tema

Una frase que explique, en llenguatge d'alumnat de 16 anys, què farem i per a què servix.

⏱ 3 hores 📍 Fase 1 · Pensament de programador 🧩 Necessites: Tema anterior ⌨️ 60-75 min programant

Una situació per començar

🎮

Imagina't que… (acíd una situació pròxima: un videojoc, una nota, una contrasenya, un preu, una llista de música…). Acaba amb una pregunta que només es pot resoldre amb el concepte del tema.

«I si l'usuari escriu una altra cosa?» «I si volem guardar 30 notes en compte de 3?»

Teoria, poc a poc

Regla d'or: una idea → un exemple. Mai dos paràgrafs seguits sense codi o esquema.

💡 Idea clau del bloc, en una frase.

Explicació curta, amb llenguatge pròxim. «Mira què passa ací…», «Ara li pegarem una volta…»

int punts = 0;              // comença el joc
punts = punts + 10;         // guanyem 10 punts
System.out.println(punts);  // mostrem el resultat
Eixida per pantalla 
10

Exemples explicats pas a pas

Cada exemple: què volem aconseguir → el codi comentat → què apareix per pantalla → per què funciona.

Exemple 1 · Un títol clar que diga què fem

Què volem? Descripció del problema en una línia.

// Cada línia fa una cosa i va comentada
int vida = 100;
vida = vida - 30;                 // rebem un colp
System.out.println("Vida: " + vida);
Eixida per pantalla
Vida: 70

Per què funciona: explicació de dos línies, centrada en el concepte del tema.

Què apareixerà per pantalla?

int a = 5;
int b = 2;
System.out.println(a / b);
Resposta
Eixida real
2

Per què: quan dividim dos enters, Java guarda un enter. El 0,5 es perd. Ací és on comença a tindre gràcia.

Programació guiada: ho fem junts

Construïm el programa pas a pas. No mostres el codi final d'un colp: pensa en veu alta, pregunta i prova cada pas abans de passar al següent.

1

Entendre què ens demanen

Què ha de fer el programa? Quines dades necessita? Què ha de mostrar?

Quina informació hem de guardar per poder resoldre-ho?

public class ElMeuPrograma {
    public static void main(String[] args) {
        // de moment ací no hi ha res: ho construirem pas a pas
    }
}
2

Afegim la primera part

Una cosa per pas. Provem, mirem l'eixida i continuem.

I si l'usuari posa un valor estrany? Què passaria?

int notes = 3;
System.out.println("Anem a calcular la mitjana de " + notes + " notes.");
Eixida per pantalla
Anem a calcular la mitjana de 3 notes.

Mini exercicis

De 4 a 8 activitats molt curtes. Un minut o dos cada una: es poden fer a classe mateix.

1

Títol curt de l'activitat

1 min

Enunciat d'una o dos línies.

Solució 
System.out.println("Hola!");

Per què: explicació d'una línia.

Fes el programa

De 3 a 5 exercicis, de menor a major dificultat. Primer es pensa, després s'escriu i finalment es prova. La solució és per comparar, no per copiar.

1

Títol de l'exercici

Fàcil 15 min

Enunciat clar: què ha de fer el programa, quines dades guarda i què ha de mostrar.

Exemple de funcionament:

Què ha de passar
Entra: 8
Ix:     La nota és un notable

Pista: una ajuda que no resol l'exercici (quina estructura fer servir, quantes variables calen…).

Solució proposada 
// Solució completa, comentada i amb una variant al final
int nota = 8;
System.out.println("La nota és " + nota);

Per què es fa aixina: justificació breu. També pot incloure una alternativa vàlida («també funcionaria amb…»).

Reptes (sense solució)

🧠

Els reptes no tenen botó de solució, a propòsit. L'objectiu és pensar, provar, equivocar-se i tornar-ho a intentar. Es poden resoldre de moltes maneres diferents: totes les solucions que funcionen són bones.

REPTE 1

Títol del repte

Enunciat obert. Ha de poder resoldre's amb el que s'ha après fins ara, però exigint pensar una miqueta més.

Ampliacions opcionals:

  • Què passa si…?
  • Com ho faries perquè també…?

Errors habituals

Els errors que apareixen segur. Saber llegir-los és mitat del treball.

Error 1

Nom de l'error en poques paraules

Codi que falla 
int edat = "16";

error: incompatible types: String cannot be converted to int

Què ha passat
Explicació curta i clara.
Per què
La raó real, no només «perquè sí».
Com detectar-ho
Com llegir el missatge del compilador o què mirar.
Com corregir-ho
La solució, amb el codi correcte.
Codi correcte 
int edat = 16;
